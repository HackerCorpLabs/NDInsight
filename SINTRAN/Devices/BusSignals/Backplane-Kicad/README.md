# Backplane KiCad Reference Design

**Third-party open-hardware backplane KiCad project, kept as a reference design for the ND-100 bus backplane / controller-card work in [../CONTROLLER-DESIGN.md](../CONTROLLER-DESIGN.md).**

Source: the RetroBrew Computers Wiki "ECB Backplane-4" project (see the `.url` file below).
This is NOT a Norsk Data design - it is a modern ECB backplane using the same DIN 41612
connector family as the ND-100 bus.
