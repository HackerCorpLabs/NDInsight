# ND Compact Backplane - Backwiring Photos

**High-resolution photographs of an ND Compact backplane board, front and back.**

The file names carry the ND print number `324409` (revision markings B3/B4 per the
file names). Board markings visible in the photos: date code `8415` on the connector
side; `6036 B` and connector position labels `PL1` / `PL12` on the solder side.

---

## Files

| File | Contents |
|------|----------|
| `nd-324409-B3.jpg` | Connector side: 12 vertical DIN 41612 female connectors on a green PCB, with discrete components (resistor packs) between some slots |
| `nd-324409-B4.jpg` | Solder/backwiring side: through-hole pin field for the 12 connector positions (PL1..PL12) and the backwiring traces |

Useful together with the pin/signal documentation in
[../ND-100-BUS-C-CONNECTOR.md](../ND-100-BUS-C-CONNECTOR.md).
