Using them inside this repo for research is one thing; putting them on a public
page is another. Do not do the second without a licence.

## Rules for this folder

- One sub-folder per machine: `nord-1/`, `nord-12/`, `nd-5000/`, and so on.
- Keep the original file name from the source wherever possible. It is often the
  only thread back to the author - `.TS` is how the NORD-1 photo's author was
  found, and `TELE-TKU-8004` is how the NORD-12 machine was identified.
- **But do not trust a file name over the picture.** `nd-5000-compact.jpg` shows a
  machine badged ND-5700.
- Never add an image without trying to find out who took it. "Found on a wiki" is
  not a source - the wiki is often mirroring someone else, as the NORD-1 photo
  turned out to be mirroring Wikimedia Commons.
- When a chapter shows an image, the caption names the author and the licence. If
  the licence is not established, the caption says that too.
