# NORD-42

*A NORD-12 built for one customer: Norcontrol, for ships.*

|  |  |
|---|---|
| **Introduced** | 1974 |
| **Type** | OEM version of [NORD-12](NORD-12.md) |
| **Word length** | 16-bit |
| **Needs a host?** | No, runs on its own |
| **Replaced** | - |
| **Replaced by** | - |
| **Survivors** | None recorded |

## The short version

Not a separate design. ND manufactured it for Noratom-Norcontrol, who used it
as the central processor in their DATABRIDGE shipboard system and in ship
simulators at maritime schools in Norway and abroad, including China and Mexico.
Norcontrol is the same company that took the very first NORD-1 sold.

## Specification

| Item | Value |
|---|---|
| CPU | As [NORD-12](NORD-12.md) |
| Instruction set | Covered by the same microprogram ROM as the NORD-10 and NORD-10/S **[P]** |
| Memory | MOS, 4Kb chips; first delivery summer 1974 |
| Used in | Norcontrol DATABRIDGE; maritime training simulators |

## What was new

- Nothing technically - this is a badge and a customer, not a design.
