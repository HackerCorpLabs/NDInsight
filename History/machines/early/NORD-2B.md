## The short version

Little is documented about this machine. It was a stripped-down and less
costly version of the NORD-1 with the same general specification but less memory.
A substantial number went to CERN, and others to Norwegian sites - including one
at Norway's National Centre for Epilepsy, where it processed live EEG signals to
detect epileptic seizures automatically. That was pioneering work for 1970.

## Specification

| Item | Value |
|---|---|
| CPU | As NORD-1, simplified |
| Memory | 4K to 16K words of core |
| Address space | 64K words |
| Control store | None - hardwired |
| Multi-machine | Two NORD-2Bs could talk over a data channel and share one I/O system |

## What was new

- Cost, rather than capability - this was the NORD-1 made affordable.
- Used in a 1970 packet-switching network built with Siemens for the Norwegian Air Force Supply Service.
