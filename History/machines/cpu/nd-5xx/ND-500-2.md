# ND-500/2

*The second implementation, and the widest-sold. The CPU behind the ND-505.*

|  |  |
|---|---|
| **Introduced** | ~1982 |
| **Type** | Implementation of [ND-500](ND-500.md) |
| **Word length** | 32-bit |
| **Needs a host?** | **Yes - needs an ND-100/110** |
| **Replaced** | ND-500/1 |
| **Replaced by** | ND-5000 Samson (1987) |
| **Survivors** | Not recorded |

## The short version

The second hardware generation, sold under five model numbers plus /CX
variants as newer front-end processors became available. It is the CPU inside the
ND-505 export machine, and it includes a **prefetch processor** that fetches data
from the multiport memory and pipelines instructions.

## Specification

| Item | Value |
|---|---|
| Sold as | ND-510, ND-530, ND-550, ND-560, ND-570, and /CX variants |
| Prefetch | A prefetch processor handles fetching from multiport memory and instruction pipelining |
| Address space | 29 bits available to the user - a quarter gigabyte for programs and a quarter for data |
| Runs | The 25 '87 extension instructions |
| Note | ND-560 is listed under both the /1 and /2 implementations; one listing is wrong **[?]** |

## What was new

- Instruction pipelining with a dedicated prefetch processor.
