# ND-500/1

*The first hardware implementation of the ND-500 architecture.*

|  |  |
|---|---|
| **Introduced** | 1981 |
| **Type** | Implementation of [ND-500](ND-500.md) |
| **Word length** | 32-bit |
| **Needs a host?** | **Yes - needs an ND-100/110** |
| **Replaced** | - |
| **Replaced by** | ND-500/2 |
| **Survivors** | Not recorded |

## The short version

The first of four hardware generations of the ND-500 architecture. Sold under
three model numbers. The '87 extension instructions introduced with the ND-5000
also run on this CPU.

## Specification

| Item | Value |
|---|---|
| Sold as | ND-520, ND-540, ND-560 |
| Architecture | As [ND-500](ND-500.md) |
| Runs | The 25 '87 extension instructions, despite predating them |
| What differs from the /2 | **Not established.** The ND-500 Hardware Description (ND-05.011.01) is listed as *not available* **[?]** |

## What was new

- First silicon for the architecture.
