## The short version

An ND-120 CPU board with faster access to its on-board memory and more of it.
This is the last CPU in the ND-100 line, dated by an engineering change order to
1994 - two years after Norsk Data itself had gone. **It rests on a single source**
and appears in no manual held in this repository.

## Specification

| Item | Value |
|---|---|
| CPU | ND-120 CPU |
| On-board memory | 8, 12 or 16 MB (the ND-120/CX maximum was 6 MB) |
| Memory parts | 4 MB SIMMs instead of 1 MB SIPs |
| Memory cycle | 150 ns, using 70 ns modules instead of 100 ns |
| Evidence | One paragraph on ndwiki, cited to sintran.com ECO 100-786 dated 1994-09-09 **[?]** |

## What was new

- More and faster memory. No change to the processor itself.
