## The short version

One of the ND-5000 models. On this line the model number is largely a
**configuration**, not a different design: the CPU type, the master clock setting
and which caches are enabled are what separate one model from the next. ND built this one to **replace the ND-570/CX**: its own sales document says the ND-5700 "has approximately the same CPU performance as the ND-570/CX".
