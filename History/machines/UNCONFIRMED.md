# Machines we cannot confirm

*Names that appear in one source and nowhere else. Kept so they are not silently
dropped, and so nobody has to rediscover the gap.*

Each of these needs one document to become a real machine. None has one yet.

---

| | |
|---|---|

| **What we have** | The folder name. That is all |
| **Contains** | Only NORD-1 manuals - nothing named NORD-4 |
| **Status** | Someone at some point expected NORD-4 documents to exist |

## NORD-2U

| | |
