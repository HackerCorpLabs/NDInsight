# MON 60B / N500M - documented subfunction list (code -> name)

Source: ND-60.136.04A ND-500 Loader Monitor ch.10, via
Developer/MON/calls/60B_N500M_Functions.md.

STATUS: **documented, NOT yet byte-matched** to the N500M dispatcher in 050-S3I5PIT.
The dispatcher category-boundary compares (SAT 15B / 40B / 61B) DO align with the
category starts below (VERIFIED from bytes), but individual code->handler mappings
are not yet byte-proven. Treat names as a hypothesis to confirm against the bytes.
VERSION NOTE: this list is from the manual; the carve is L07 - reconcile if they differ.


## Category 1: System Services (0B - 14B)
  0B - RRREG (Read Register)
  1B - WRREG (Write Register)
  2B - RPROG (Read Program Memory)
  3B - RDATA (Read Data Memory)
  4B - WPROG (Write Program Memory)
  5B - WDATA (Write Data Memory)
  6B - PLACE (Place Segment)
  7B - SWLOD (Load Swapper)
  10B - RRREG_BLOCK (Read Registers Block)
  11B - WRREG_BLOCK (Write Registers Block)
  12B - RUNN (Start Program)
  13B - CNCFI (Connect File)
  14B - CLSFI (Close File)
