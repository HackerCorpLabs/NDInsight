
%% PATCHING PROCEDURE:
%% ===================

%% BEFORE 22! IS TYPED, PATCHES TO THE SYSTEM CAN BE DONE BY CALLING
%% A  SET OF MACROES FOR THIS PURPOSE.
%% THE MACROES ARE CALLED BY ENTERING THE MACRO-NAME FOLLOWED BY
%% CARRIAGE-RETURN AND LINE-FEED.

%% MACRO NAMES AND CORRESPONDING AREA:
%% -----------------------------------------------------------------
%%     - PCCST               COMMON-CODE AND START ROUTINES
%%     - PRDAT               RESIDENT DATA PART ONE
%%     - P2RDA               RESIDENT DATA PART TWO
%%     - PSYSG               SYSTEM SEGMENT
%%     - PSPDF               SPOOLING DATAFIELDS
%%     - PEXCO               EXT  COMMON (RPIT MPIT IPIT)
%%     - PRPIT               RPIT
%%     - PMPIT               MPIT
%%     - PIPIT               IPIT
%%     - PFILS               FILE-SYSTEM AND SPOOLING PROGRAM
%%     - PRTLO               RT-LOADER
%%     - POPCO               COMMAND SEGMENT
%%     - PSERV               SERVICE AND MAIL SEGMENT
%%     - PERRP               ERROR-PROGRAM
%%     - PSGTB               SEGMENT TABLE
%%     - P500M               ND-500 MONITOR
%%     - PDIMI               DISK MIRRORING
%%     - PXMK                XMSG KERNEL
%%     - PXRO                XMSG XROUT
%%     - PXFI                XMSG WATCHDOG
%%
%%     - PEND                RESET CORE-IMAGE BEFORE STARTING!
%%
%%     I M P O R T A N T !
%%     THE MACRO / PCCST/ MUST ALWAYS BE USED BEFORE STARTING
%%     IF ANY OF THE OTHER MACROES HAVE BEEN USED.
%% -----------------------------------------------------------------
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%  )9BYTT PARAMETRES ARE AS FOLLOWS:
%%  NO  1:  MSTYP  - SYMBOL USED:  F
%%  NO  2:  DEVNO  - SYMBOL USED:  G
%%  NO  3:  CORAD  - SYMBOL USED:  D  (DUMMY)
%%  NO  4:  LONG   - SYMBOL USED:  D  (DUMMY)
%%  NO  5:  CLM    - SYMBOL USED:  D  (DUMMY)
%%  NO  6:  BLST   - SYMBOL USED:  D  (DUMMY)
%%  NO  7:  DRES   - SEE BELOW
%%  NO  8:  CRMAX  - SYMBOL USED:  A
%%  NO  9:  MACAD  - SYMBOL USED:  D  (DUMMY)
%%  NO 10:  DASA   - SYMBOL USED:  H
%%
%%  SYMBOLS FOR PARAMETER 7: (CORE IMAGE ADDRESS)
%%      EP       - ERROR PROGRAM
%%      RL       - RT-LOADER
%%      CCS      - COMMON-CODE AND STARTUP ROUTINES (SEGFIL0 START)
%%      RD       - RESIDENT-DATA  PART ONE
%%      SY       - SYSTEM SEGMENT
%%      SPD      - SPOOLING DATAFIELDS
%%      XP       - EXT COMMON
%%      RP       - RPIT
%%      MP       - MPIT
%%      IP       - IPIT
%%      STB      - SEGMENT TABLE
%%      FS       - FILE SYSTEM
%%      CS       - COMMAND SEGMENT
%%      SM       - SERVICE MAIL SEGMENT
%%      5P       - 5PIT
%%      5M       - ND-500 MONITOR
%%      DM       - DISK MIRRORING
%%      XK       - XMSG KERNEL
%%      XR       - XMSG XROUT
%%      XF       - XMSG WATCHDOG
%%      NM       - DEVICE NAME TABLE SEGMENT
%%      NS       - NUCLEUS SERVER
%%      NN       - NUCLEUS NAME SERVER
%%      U1       - MICRO CODE 110
%%      U2       - MICRO CODE 120
%%      EC       - ERROR WATCH-DOG CODE
%%      ED       - ERROR WATCH-DOG DATA
%%      PM       - PROCESS MANAGER
%%      ES       - EVENT   MANAGER
%%      PB       - BOPCOM SERVER
%%      MT       - MTSERV
%%
%%  NOTE THAT THE ABOVE SYMBOLS STATES BLOCK ADDRESSES FOR THE
%%  RESPECTIVE AREAS AND MUST BE CALCULATED FROM PAGE NUMBER
