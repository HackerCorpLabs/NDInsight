## LOADING/OPERATING PROCEDURE

Read this installation procedure carefully before performing the installation! An installation sample is given.

The loading of a new version of NOTIS-WP is fairly simple. You will be guided through the installation by self-explanatory questions asked by a program called INSTALL-WP.

### SINTRAN requirements:

- Sintran **version H** or later is required.

- Sintran must have been generated with the XON/XOFF option.

- It must be possible to use break and echo strategy no. 7 (user defined strategies). This is the default when generating a new version of Sintran.

- The background segment size must be set to 128 pages on each of the terminals on which you wish to run NOTIS-WP.

- The terminal file **must** be called TERMINAL. If this is not so, use the Sintran command **@SET-TERMINAL-FILE "TERMINAL"** from user System.

- The total required space on the segment files is **189 pages** (275 octal) + **63** (77 octal) for each additional language.

The four contiguous areas that are required must be at least **64, 62, 48** and **15** pages. Each additional language requires two contiguous areas of **48** and **15** pages. To find out how much space is available, use the RT-LOADER command **DUMP-SEGFILE-BITMAP,...**. This gives you the total number of pages and the number of contiguous pages available (in octal).

If you have either Philips GP-300 L (ND-408/410) or Epson-MX80 (NO-423) printers, you must ensure that XON/XOFF communications protocol has been set both in Sintran and on the printers.

### Changing Sintran version:

If NOTIS-WP is being installed under Sintran version H, and you change to version I at a later time, the installation procedure must be performed once more. This second time you should specify that you wish to make changes to the current installation (answer C to the question "Install or Change" (See sample)). This is only necessary when going from version H to version I of Sintran.

### Memory requirements:

In the most difficult work situations (big documents, lots of searching/substitutions, heavy text formatting), NOTIS-WP requires 64K words of memory + 36K words per simultaneous user. During normal use, the requirements are 25K words + 20K words.

### Disk space requirements

NOTIS-WP uses the scratch-files under user SCRATCH for temporary storage of documents during editing. The space requirements for user SCRATCH are approximately:

\[ 2 + \frac{28 * N}{750} \] L pages per region.

- 'N' = Average number of characters per line of text
- 'L' = Average number of lines per region

### Installation Requirements

Before the installation can take place, there are a few things that need to be done:

- Make sure that the standard program FMAC is available as a reentrant subsystem or as a :PROG version under user SYSTEM.

- Check that user SYSTEM has at least 210 unused pages (+ 130 per additional language) and space for at least 12 new files (+ 4 per additional language).

**Note:** Each user may have a maximum of 256 files per directory.

- Determine a user for the :BPUN files (normally used: 8PUN-FILES) and check that this user has at least 200 unused pages on his default directory (+ 70 for each additional language) and space for at least 4 new files (+ 2 per additional language).

- Ascertain that user SYSTEM has default directory access to this user's files in order to give SYSTEM the right to create new :BPUN files.

- Ascertain that the following files do **NOT** exist on user SYSTEM's default directory:

  ```
  INSTALL-WP:COM
  INSTALL-WP:TEMP
  XCOM:PROG
  ```

### WP-PRINTERS-K:SYMB

This is an ordinary text file, see next page for layout.

This file should be edited to suit your installation's set of printers according to the fairly self-explanatory instructions therein. Note that the printer names must be the exact match of the installation's peripheral or spooling file names. The Logical printer name is the name under which you wish to use the printer, and is independent of the real Sintran-III file name.

This means that the NOTIS-WP user does not need to know which machine each printer is actually connected to. You may even use a printer under several names, but with different default values such as nationality, page width etc.

It will also be necessary to **remove** those entries which **do not** apply to your system.
