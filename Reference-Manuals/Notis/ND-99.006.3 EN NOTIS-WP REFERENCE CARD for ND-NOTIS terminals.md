# F-keys

| Key  | Action                                                                 |
|------|------------------------------------------------------------------------|
| F1   | Delete current line                                                    |
|      | **SHIFT+F1** Turn graphical character set on/off or draw boxes or lines|
| F2   | Insert blank line above current line                                   |
|      | **SHIFT+F2** Turn Greek character set on/off                           |
| F3   |                                                                        |
|      | **SHIFT+F3** Turn mathematical character set on/off                    |
| F4   | Calculate numbers in block or SHIFT+FIELD marked text                  |
|      | **SHIFT+F4**                                                           |
| F5   | Split line at cursor position                                          |
|      | **SHIFT+F5** Join line where cursor is to line above                   |
| F6   | Change uppercase to lowercase in marked text or rest of field          |
|      | **SHIFT+F6** Change lowercase to uppercase in marked text or rest of field |
| F7   | Move to next occurrence of text specified by SHIFT+F7                  |
|      | **SHIFT+F7** Move directly to a specified text (find text)             |
| F8   | Define, fetch, list, store or delete standard text                     |
|      | **SHIFT+F8** Define, fetch, list, store or delete clippings            |

# Edit Ruler

```
     Fetch copy of                      Fetch copy of 
     controlling                       document normal 
     ruler or set                      ruler or set
     left margin                       right margin
  ( ... )                             SHIFT + ( ... )
  ( ... )                                    ( ... )
```

```
     Start wordwrap                     Stop wordwrap
     area                               area
  aaa                              SHIFT + aaa
  aaa                                     aaa
```

```
     Mark wordwrap                      Move marked
     part of ruler                      wordwrap area
                                        on ruler
  FIELD                             MOVE
```

```
     Set or remove                      Set or remove
     tabulator stop                     decimal tabulator
     in cursor                          stop in cursor
     position                           position
  TAB                               SHIFT + TAB 
  +                                         +
```

# Store Ruler

```
     Store new ruler                    Store new ruler
     and justify text                   and justify text
     from old wordwrap                  in new wordwrap
     area into new                      area
     
    (arrow)                            (arrow)
```
