## Vennligst legg merke til:

Dette er et referansekort for M-versjonen av NOTIS-WP. Kortet vil bli oppdatert og trykket som et sammenleggbart oppslagskort på A6-format når N-versjonen av NOTIS-WP foreligger. Dersom det skulle være noen kommentarer til kortets innhold, vennligst benytt kortets bakside og send til:

```
Norsk Data A.S  
Doc.dept.  
Pb. 78  

N-7001 TRONDHEIM
```

# Utskriftsdirektiver

```
*H1-tekst;           Første sidehode
*H2-tekst;           Andre sidehode
*TL-tekst;           Sidetlo
*PH=n;               Utskrift av sideshoder
*PG=n;               Ny side
*PN=n;               Sidnummer
*Y=n;                Linjetetthet (linjer pr. Inch)
*HP=n;               Horisontal tettethet (tegn pr. Inch)
*DX=n;               Dobbeltsidig kobling
*FONT=n;             Velg skrifttype
*T=tekst;            Skriv tekst i annen skrift
*BP=++;              Uthevet skrift på
*BP=-;               Uthevet skrift av
*B=tekst;            Uthevet tekst
*DATE;               Skriv dagens dato (dag.mnd.år)
*YEAR;               Skriv året i dag
*MM;                 Skriv måned i dag
*DD;                 Skriv dagen i dag
*HD-tekst=R=;        Halv linje ned
*HU-tekst=R=;        Halv linje opp
*BIN IN=1;           Urmarkertskrutt
*BIN OUT=n;          Utskriftsskuff
*IN.BJD=           Inkluder diagram eller tegning
*CHAP-tekst;         Start nytt kapittel
*CHAPTER-tekst;      Start nytt kapittel med forside
*CHPG-tekst;         Start nytt kapittel med ny side
*CHPG-OLD-tekst;     Start nytt kapittel på utvidet anndnummer
*SECTO-tekst;        Start nytt underkapittel på nytt nivå
*SECTU-tekst;        Start nytt underpoopnett på samme nivå
*SEC=tekst;          Start nytt underkapittel på forrige nivå
*CO;                 Kabelnummer
*CC-tekst;           Kommentar på skjerm, skrives ikke ut
*BL;                 En blank linje
*PL=n;               Side lengde
*PW=n;               Side bredde
*LM=n;               Vennstre kant
*NM=n;               Høyre kant
*CPF-tekst;          Øvre kant
```
