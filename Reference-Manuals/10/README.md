# NORD-10 Manuals

**Reference, hardware, and operations documentation for the NORD-10 / NORD-10-S minicomputer**

[← Reference Manuals index](../README.md)

---

## 📖 Overview

This sub-collection holds the NORD-10 / NORD-10-S documentation set: CPU reference and
microprogram, communication with the NORD-50, operator's guides, verification programs,
disc system, and hardware/wiring descriptions. Source material for the NORD-10 generation
that preceded the ND-100.

| Manuals | Total Lines |
|---------|-------------|
| **13** | ~58,600 |
