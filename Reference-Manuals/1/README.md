# NORD-1 Manuals

**Reference and hardware documentation for the NORD-1 - Norsk Data's first minicomputer (1968-1972 era)**

[← Reference Manuals index](../README.md)

---

## 📖 Overview

This sub-collection holds the NORD-1 documentation set: the CPU reference manual, the
two-volume hardware manual, the connector / I-O-channel / power-system description, and a
peripheral binder. Primary source material for the earliest Norsk Data architecture.

| Manuals | Total Lines |
|---------|-------------|
| **5** | ~16,800 |
