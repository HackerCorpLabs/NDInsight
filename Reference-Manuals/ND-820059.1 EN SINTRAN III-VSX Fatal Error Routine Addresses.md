# SINTRAN III/VSX Fatal Error Routine Addresses

## Introduction

### 1. Introduction

When a fatal error occurs in SINTRAN III, the routine ERRFATAL is called, and the following message is written to the error device (or console terminal):

    System Malfunction. SINTRAN halt in ERRFATAL, L-reg: xxxxxx
    Current page index tables (NPIT/APIT): YY / ZZ
    Level: WW

    Some further information if ERRFATAL was called from level 14.

On the following pages, you will find lists of which routine in SINTRAN called ERRFATAL, based on the given PIT (NPIT = Normal PIT) and L-register contents (address of the call to ERRFATAL).

The lists are sorted on PIT number.

All addresses are octal numbers.

The routine addresses are given for the standard configurations A and B for both the L- and M-versions of SINTRAN III/VSX.
