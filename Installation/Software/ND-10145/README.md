## What is known
A high-level language for building tabular financial models — data stored in named tables (rows/
columns), a database subsystem for storing them, interactive or batch execution, calculations
within/between tables. On the market since 1976; available on NORD-10 and ND-100. [PI] The PI
sheet is marketing/feature material only — it does not carry an install procedure. No PD sheet
and no floppy image (checked against `floppies.json`, 899 entries) has been located for this
article number.
