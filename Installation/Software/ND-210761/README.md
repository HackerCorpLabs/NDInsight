## Description
The C compiler for the ND-500. Ships with its own runtime library, headers (`C-Include`), and a
linker/loader environment; user-facing docs are in the combined
`ND-60.214.01 CC-100 and CC-500 C-Compiler User Manual` (both CPU targets share one user manual,
but installation is per-CPU and per-product). [PD]
