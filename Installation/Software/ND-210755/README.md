## Description
Compile and execute BASIC programs on the ND-500. Ships as an ND-500 domain (`:LINK`/`:DSEG`/
`:PSEG`) plus a separate `:NRF` runtime library — same distribution shape as `ND-210190`
FORTRAN-for-ND-500 and `ND-10177`/`ND-210177` COBOL. **This product was completely missing from
this catalog** — added now with a full, real PD sheet. `[fixed 2026-08-10]`
