## Description
Converts ND-500/5000 compiler output (NRF) into executable DOMAIN files, with up to 32 program +
32 data segments per domain (vs. NLL's 30+30), self-contained domain files, a link-lock/link-key
consistency mechanism, and a job-control language for per-source-language auto-load/auto-link
actions on `CLOSE`. Full feature description:
[../../Product-Info/ND-211224-A1-EN.md](../../Product-Info/ND-211224-A1-EN.md). [PI]

**No PD sheet has been located.** This product was also missing from this catalog's own index
entirely — added now that a real floppy for it was confirmed. `[fixed 2026-08-10]`

## Article-number correction: the Linkage-Loader is `ND-210319`, not just `ND-10319`

This product's own PI sheet states plainly: "A subsystem called CONVERT-DOMAIN (ND 211229)
supports conversion from the format generated by the LINKAGE LOADER (**ND 210319**) to the
current domain format." This confirms the floppy `210319H02-XX-01D` already documented live in
[../../INSTALL-ND-LINKAGE-LOADER-AND-BACKUP-SYSTEM.md](../../INSTALL-ND-LINKAGE-LOADER-AND-BACKUP-SYSTEM.md)
belongs under article `ND-210319` — the later `21`-prefixed article, per this catalog's usual
volume-name convention — not the older `ND-10319` (which has its own genuine PI sheet, a real,
separate article number, same base/later-revision pattern seen throughout this catalog, e.g.
`ND-10337`/`ND-210337`). Neither `ND-10319` nor `ND-210319` yet has its own product folder in
this `Software/` framework; the live-verified install lives only in the standalone doc linked
above.

## A genuine installer, same shape as the already-verified NLL installer

`211224B01-XX-01D` carries `IN-LINK-XX-B01:PROG`/`:XCOM`/`:INIT` — the **exact same three file
types** as the NLL installer (`IN-NLL-XX-H02:PROG`/`:XCOM`/`:INIT`), unlike the FORTRAN K02
installer (which uses `:RSRC` instead of `:XCOM`). This is a much closer structural match, so the
NLL installer's already-observed module flow (Get start information → Delete product files →
Check environment and resources → Copy product files → Exit, all gotchas in
[../../INSTALL-ND-LINKAGE-LOADER-AND-BACKUP-SYSTEM.md §5](../../INSTALL-ND-LINKAGE-LOADER-AND-BACKUP-SYSTEM.md))
is a strong candidate for how this installer behaves too — but this is analogy, not confirmation;
see [ND-211224B01](ND-211224B01/README.md).
