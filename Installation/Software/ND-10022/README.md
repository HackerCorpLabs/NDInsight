## Description
A package of SINTRAN III utility programs run from a distribution floppy — e.g. floppy/disk
tools such as `MCOPY`, `FLOPPY-MON`, `FILSYS-INV`, `COP-VERIFY` (program names observed on
SINTRAN utility/floppy media). [WIKI/OBS]
