# 4 Installation Procedure

## 4.1 Automatic Installation

### 4.1.1 Preparations

Prior to the installation, verify the following:

- Ensure that the user areas specified in Chapter 1.3 exist with the required number of free pages and free files. If not, find a directory having enough space to hold the user areas. The installation program will try to allocate space whenever needed, but you may need to specify on which directory to create user areas.

- The following files will be loaded with UNIQUICK:

| Abbrev.    | File Name | Default User Area(s)  |
|------------|-----------|-----------------------|
| SIBAS libary | SIB-LIB | SIB-500               |
| UE library   | UE-PLIB | USER-ENVIRONMENT      |

Check where these files are installed. If not installed on the default user area, the installation program will ask where to find these files.

- Ensure that your configuration fulfills all other requirements mentioned in Chapter 1 and 2.

### 4.1.2 Installation from Floppy

- Put the diskette 210871C<rev>-XX-01D into the floppy drive.
- Log in to user area SYSTEM.
- Enter directory 210871C-XX-01D.
- Run the INSTALL program on the diskette.

Example: How to enter the directory and start the installation program (user input is underlined).

```
@ENTER-DIRECTORY 210871C-XX-01D FLOPPY-DISC-1 0↵

@(210871C:FLOPPY-USER)INSTALL↵
```

- **CREATE**: Create a new user area (or verify an existing one) for UNIQUICK.
- **COPY**: Copy all files from the floppy to the desired user area.
- **LOAD**: Write the load procedure and load the UNIQUICK program files.
- **DUMP**: Dump UNIQUICK as a reentrant program.
- **EXIT**: Leave the installation program and return to SINTRAN.

The first time, run all the tasks 1-4, one at a time, in sequence. To reload UNIQUICK, run tasks 3 and 4. To re-dump UNIQUICK, run task 4.

## 4.2 Non-Automatic Installation

Create a user area with the number of pages mentioned before and copy all the :BRF and :MODE files from the floppy into it.

Log in to the user area containing the :BRF files. Edit the file QUIC-LOAD-S1-C:MODE to suit your configuration and run it by typing:

```
@MODE QUIC-LOAD-S1-C:MODE "QUIC-LOAD-S1-C:LIST"
```

Update the file `QUIC-DUMP-S1-C:MODE` in the same way and run it from user SYSTEM. Remember to update the system startup file (see also section 4.1.2).

# 5 Modifications

## 5.1 New Functions/Commands

### Revision C10

- UNIQUICK has been rewritten with a new user interface and new application generating routines.

- Advanced applications can be made using many tables (owner-member structures and join structures) and most UNIQUE-II field functions are available.

- The word "Letter" (language dependant) is displayed in the status line if you have some unread electronic mail (NOTIS-ID).

- New terminology has been introduced in the DIALOGUE family. UNIQUICK uses the new terminology.

- UNIQUICK now reads the parameter `prefix-source=` from the SW-CONFIG file, under `system-name:<domain-name>` or `system-name:0`. `system name:0` denotes parameters valid for all UNIQUE systems.

- There is an additional configuration parameter, `UNIQUE-ON-LINE=`, which is not documented in the manual. This is used to tell UNIQUICK the name of UNIQUE-II if the standard name is not used.

UQ-ND-S:INI is an 'empty' file containing only an S-Format header matching the version of NOTIS-WP you are using on your machine. By storing the S-Format header in a file, it is possible for you to define the default settings and rulers. UNIQUE will read the default header from this user-defined file, if it exists.

If you start using a version of NOTIS-WP with a new S-Format, e.g. going from WP version M to N, just repeat the procedure described below and UNIQUE will produce documents readable by the new WP version.

You have to install/create this file manually:

```
1. Log in on user area DIALOG-SYS.
2. Start NOTIS-WP.
3. Use the internal menus in WP to set the wanted default values.
4. Make sure you define it to be an S-Format document.
5. Type some blanks so WP will store it as a document.
6. Save this 'empty' document to the file "UQ-ND-S:INI".
7. Set public access to READ: @set-file-access UQ-ND-S:INI R R,,,
```
