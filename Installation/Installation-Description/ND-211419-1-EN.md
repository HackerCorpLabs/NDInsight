## 1 INSTALLATION PROCEDURE

- Log in as user SYSTEM.

- Insert the floppy diskette 211419A<rev>-<lang>-01 into the floppy-drive.

- Enter the directory:

  ```
  @ENTER-DIRECTORY ↵
  DIRECTORY NAME: ↵
  DEVICE NAME: <device name> ↵
  DEVICE UNIT: <device unit> ↵
  ```

- Start the installation program:

  ```
  @(211419A<rev>:FLOPPY-USER)IN-FO-LO-<lang>-A<rev> ↵
  ```

- The installation program is self-explanatory.

2 HOW TO USE THE FONT-LOAD PROGRAM
==================================

Start the FONT-LOAD program by typing:

      @(<user>)FONT-LOAD-<lang>-A<rev> ↵

First you select the printer type from a menu. (PHILIPS GP300OL or ND 616CN). Navigate to the correct printer type and press ↵.

The program will then ask for the logical name of the printer you want to down-load fonts to. If you enter the name of a mass storage file, the program will write the fonts to this file and you can later use this file as a setup file.

A menu containing available font files will now appear on the screen. First you select the font you wish to load as font 7, then the font you wish to load as font 8, and finally the font you wish to load as font 9. If every one of these fonts has the right format, they will appear in their fields, and the program will down-load them into the printer (or write them to a setup file).

When the down-loading is finished the screen will be cleared and the program terminates. Now you can use these fonts with the FONT-directive in NOTIS-WP.

For help you can also use the <HELP> key when running the program.
