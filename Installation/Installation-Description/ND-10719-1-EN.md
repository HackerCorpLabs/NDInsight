## 1 Loading

Files are copied to user SYSTEM for the logged-in user. APPLE LINK should reside on user SYSTEM to be available to all users, or be dumped resident on SINTRAN 3, or later, by the command:

```
dump p:prog>pr. apple-l:dir. <apple j:dir.:>
```

## 2 Operating Procedure, Use

### 2.1 APPLE-LINK

APPLE LINK, running on the ND-110/100, handles file transfer to and from ND LINK running on the APPLE II. The program is started easily by entering the CENTRAL command:

```
@apple-link<CR>
```

APPLE LINK operates as a server from one simple-to-follow menu. Online help is also available for the users.

### 2.2 VTM-COMPOUND

The supplied VTM table, DD8807A-A:AVTM must be compounded into the VTM DD8ARRAYSEE or DD8ARRAYSB: Terminal type 87 must be selected before the APPLE file running an ND-LINK becomes a TDV110E, like N0TIJS terminal.

When DD8807A-A:AVTM has been compounded into the selected VTM table/array, the right terminal type is set by entering the SINTRAN command:

```
@set terminal type .. 0, x<CR>
```

where x is the APPLE terminal line number. To make the setting permanent, the above command must be entered in the SINTRAN command file.

Version A of VTM uses the file called DD8nnn-A:AVTM. The file DD8nnn-A:VTM originally contains the terminal type description for the standard terminals.

Version B and later versions use one composite file. In version B, this file is called DD8ARRAYSB:VTM. In version C, and later versions, it is called DD8ARRAYSEE:VTM. These files contain resident data, so if version B is to be used, one will have to preserve the file.

## RENAME FILE DDBTABLES:Ø:VTM DDRARRAYS-B:VTM

If wanted, the compounded terminal tables can be loaded together with the application running VTM. In this case, VTM-ARRRAYS-D:NRF (NO 500) files or VTM-(1B/2B)-ARRAY-D:BRF (ND-100) files are loaded together with the program system.

This version of the system is compiled with the PLANC compiler released 7. June 1983.

## 2 VTM-COMPOUND

The compounded DDB files in the composite files are originally, the standard terminal types for ND. The types are:

| Code | Type                                              |
|------|---------------------------------------------------|
| 000  | Teletype-ASR-33                                   |
| 003  | Tandberg TDV2115 Standard                         |
| 004  | Infoton 700-1                                     |
| 005  | Infoton 400                                       |
| 011  | Dec LA36 (Typewriter 11)                          |
| 037  | Tandberg TDV2215 Extended                         |
| 052  | Tandberg Teletype ASR-33                          |
| 053  | Tandberg TDV220/9 ND-NOTIS                        |
| 057  | Facit-4420-ND-NOTIS                               |
| 083  | Tandberg-TDV2200/9-V2-ND-NOTIS                    |

VTM-COMPOUND can add or delete DDB files in DDBTABLES n:VTM, or add or delete terminal type descriptions in D008999-A:VTM. It can also create n:v.t: (with BRF (ND-102) or NRF (ND-500) format) with the compounded file DDBTABLES-n:VTM as input. This means that if a new DDB file (for a nonstandard terminal type, for example type C) is to be implemented, one has to do the following:

- 14 versions from VTM-B onward are used.

1. Add the DDB file to the compounded file, for example DDBTABLES Ø:VTM by giving the following command to VTM COMPOUND:

```
ØVTM-COMPOUND
2 % (Add TERMINAL TYPES)
7 % (DDBTABLES n:VTM)
0 % (In Version)
87 % (New DDB file)
777 % (No more DDB files)
9 % (EXIT)
```

## Commands

1. Generate the files with NRF or BRF (1-bank/2-bank) format by using the following command to VTM-COMPOUND:

```plaintext
ØVTM-COMPOUND   
  4   Z   (GENERATE A FILE WITH BRF/NRF FORMAT)
  2   Z   (DDTABLES-n:VTM)
  0   Z   (D Version)
  1   Z   (ND-100 (1-bank))
  2   Z   (ND-100 (2-bank))
  3   Z   (ND-5000)
  4   Z   (RETURN)
  0   Z   (EXIT)
```

- If VTM-A is used:

1. Add the terminal type description of the new terminal type to DØ999-A:VTM by using the following commands to VTM COMPOUND:

```plaintext
ØVTM COMPOUND    
  C   Z   (EDIT THE CONTENT IN DØ999.A:VTM)
  C   Z   (ADD TERMINAL TYPE DESCRIPTION)
  87  Z   (Terminal type)
  77  Z   (No more terminal types)
  0   Z   (EXIT)
```

VTM COMPOUND-A can be used with every version of SINTRAN, and can be run on every terminal type, provided a corresponding DDTABLE exists under the logged-in user or under user SYSTEM.

VTM COMPOUND D-C requires SINTRAN version H or later, and can only be run on one of the standard terminal types (these tables are included with the program).
