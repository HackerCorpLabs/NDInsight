## 1. OBJECT DESCRIPTION

The object product Backup Manager is a program system for backup and restore on ND-500 and -5000 computers. The C01 version also offers handling of UNIX TAR (Tape Archive) format on magnetic tape/streamer (read/write/list). Backup Manager consists of four modules:

- **BM-DEFINITION:** To predefine sets for backup and restoring
- **BM-OPERATOR:** To run predefined sets, do occasional copying and service functions.
- **BM-SCHEDULER:** To schedule backup sets and ordinary SINTRAN-III batch jobs in a COSMOS network. It consists of a server (ND-100 RT-program) and a userinterface program.
- **BM-FILERESTORE:** To restore single files from image (device) backups stored in volume format on tape or disk.

## 4. Compile Instructions

- To compile a Backup Manager module do:

  1. Enter `BM-SOURCE-C01`
  
  2. `@APPEND-BATCH 1 BM-<Module>-COMP:BTCH,BM-<Module>-COMP:BOUT`
  
     where `<Module>` is:

     | SCHED  | - for BM-SCHEDULER user interface       |
     |--------|----------------------------------------|
     | SERVER | - for BM-SCHEDULER server program       |
     | OPERAT | - for BM-OPERATOR                       |
     | DEFINIT| - for BM-DEFINITION                     |
     | FILERE | - for BM-FILESTORE                      |
     | COPLIB | - for BM-COPLIB:NRF                     |

The NRF-files will be placed on userarea `BM-NRF-C01`.

**NOTE!** To avoid problems when compiling, these batch files should be run one after the other, in sequence, on one batch processor.

- To compile the JOB conversion program (`BM-JOB-CONVERT:DOM`):

  On user `BM-SOURCE-C01`:

  `@MODE BM-JOB-CONV-COMP:MODE BM-JOB-CONV-COMP:OUT`

  - this program converts a B-version of the BM-Definition JOB db into a C-version (new structure):

```
   (ND-OPERATIONS)BM-JOBDB-B:DATA -> (ND-OPERATIONS)BM-JOBDB-C:DATA
```
