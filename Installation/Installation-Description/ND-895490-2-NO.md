## 4 Installasjonsprosedyre

### 4.1 Automatisk installasjon

```
-------------------------------------------------------------
| MERK:                                                     |
|                                                           |
| Hvis du fikk dette produktinformasjonsarket sammen med ett|
| av produktene 211306C, NTX-SPELL for ND-500(0L) eller     |
| 211564C, NOTIS-SPELL for ND-500(0L), kan du se bort fra   |
| den følgende installasjonsprosedyren og heller følge den  |
| prosedyren som følger med produktet.                      |
-------------------------------------------------------------
```

Sett disketten inn i diskettstasjonen, og åpne katalogen ved å skrive `ENTER-DIRECTORY :F-D-1.stasjon`. Hvis du skal installere mer enn ett språk, spiller det ingen rolle hvilken diskett du setter inn først.

Start installasjonsprogrammet ved å skrive `(@211573:FLOPPY-USER)IN`. Installasjonsprogrammet vil fortløpende gi deg beskjeder om hva du skal gjøre underveis.
