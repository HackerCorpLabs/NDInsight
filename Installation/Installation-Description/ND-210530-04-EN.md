## 1 Errors Corrected

- The EPSON printer may be used without patching the program.

- It is no longer possible to make recursive algorithms that crash the program.

- The file-handling routines are totally rewritten.

## 2 Known, But Not Corrected Errors

- Error in NOTIS-CALC User Guide. In the section of the User Guide explaining how to give commands with the HELP information displayed, it is stated that you press the down arrow to move the cursor back to the command line. This does not work: you must use the HOME key. To clear the HELP display you must press CANCEL twice; the first CANCEL also moves the cursor to the command line.

## 3 Changed Prerequisites

- It is now possible to run NOTIS-CALC on a non CX machine.

- You may run on all CPUs.

- You need SINTRAN III version I or later.

## 4 Modifications

### 4.1 Changed Commands

There has been a general change in handling command parameter input. All the parameters will now be shown when you enter the command. In the previous version the parameters appeared up when you pushed the down arrow key.

It is now possible to make a shortcut in the parameter input by using the EXECUTE key. CARRIAGE RETURN moves you to the next parameter or, if it is the last parameter, the command will be executed.

```
ooo  ND Norsk Data  ooo
```

- The justification command has been changed. To set default justification you must now push `">>"` for right, `"<<"` for left and `";"` for center. The next parameter is "Numeric or Text". This makes it possible to set different defaults for text and numeric cells.

- To make it possible to use IMPORT/EXPORT, we have given the `W` command an extra parameter. This parameter asks the user whether he/she wants to save the whole sheet with all subsheets, or just the subsheet.

### 4.2 NEW COMMANDS

- Import/export values and texts between sheets (Z , Y).

- List imports/exports in a sheet (FUNC+Z, FUNC+Y).

- Read a non `:CLCB` document into NOTIS-CALC (WP file, RG file, etc.) (R).

- Interface for creating input files for NOTIS-BG (B).

- Command for getting information about each key (SHIFT+HELP).

- Set numeric format (Normal, Scientific, Commercial, European commercial and Percent) (N).

- Rejustification of cell/area (right, left, center).

- Get information about a cell (CTRL+V).

### 4.3 REMOVED COMMANDS

The commands (CTRL+W) and (CTRL+R) are now removed. These commands made it possible to log every keystroke made from the terminal. The reason for removing them is that we now use NDP for input.

The possibility of creating new subsheets is removed. This is both the (G) command and reading a sheet as a subsheet.

```
ooo   ND Norsk Data   ooo
```

# 5 INSTALLATION PROCEDURE

The system may be delivered on:

- 0.3 Mbyte, 8 inch single sided-diskettes, or
- 1.2 Mbyte, 8 inch or 5 1/4 inch double-sided diskette.

You have to use the same kind of diskettes throughout the entire installation. You will be asked a few questions during the installation, but these should be self-explanatory.

Before you start the installation, you must decide on which user you want to put the program. The default user will be UTILITY, but you can put it wherever you like.

## Older versions of NOTIS-CALC for ND-100

The installation procedure will not remove NOTIS-CALC versions A, B or C. If you need the disk space for this installation, you must remove the program manually.

## How to start the installation:

- Log in as SINTRAN user SYSTEM.
- Insert the diskette with the directory name 10530D<rev>-<lang>-1D for the 1.2 Mbyte diskette, or 10530D<rev>-<lang>-1S for the 0.3 Mbyte diskettes.  
`<rev>` must be replaced by the current revision of the product, and `<lang>` with the appropriate language version, that is, EN for English, NO for Norwegian, SW for Swedish or DA for Danish.
- Execute these commands (operator input is underlined and parameters are enclosed in angle brackets):

```
@ENTER-DIRECTORY∖
DIRECTORY NAME:10530D∖
DEVICE NAME:FLOPPY-DISC-<drive-no.>∖
DEVICE UNIT:<floppy-unit>∖
@(10530D:FLOPPY-USER)INST-NC1-<lang>-D<rev>∖
```

The installation procedure is now started and you can follow the instructions given by the program to install NOTIS-CALC.

## 6 DUMPING NOTIS-CALC for ND-100

NOTIS-CALC needs two program segments to run. The dumping of the program the first time is done by the installation procedure. The installation procedure creates a file which should be called from your DUMP-REENTRANT file. The file will be put on the same user as you put NOTIS-CALC. The name of the file is:

```
NCALC-DMP-<lang>-D<rev>:MODE
```

To dump NOTIS-CALC every time you make a cold start, put this into DUMP-REENTRANT:

```
(user)NCALC-DMP-<lang>-D<rev>:MODE
```
