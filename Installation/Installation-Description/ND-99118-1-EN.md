# SCSI: General Information

## SCSI Standard

The SCSI (Small Computer Systems Interface) standard is used for connecting mass storage devices to Norsk Data computer systems. It is organized as an 8-bit SCSI bus with intelligent interfaces in each device and computer. A maximum of eight units (including the ND-100 SCSI Adaptor) can be connected to each SCSI bus. This system is very flexible, since:

- New devices can easily be connected to the bus.
- Several computers can be connected to the same SCSI bus.
- The same computer can be connected to several SCSI buses.

## ND-100 SCSI Adaptor

The ND-100 PCB 350004 FLOPPY/SCSI contains both the old floppy controller circuitry and the SCSI adaptor to the ND-100. This card interfaces the ND-100 to one SCSI bus. You can install up to four SCSI adaptors in one ND-100.

# SCSI ID Number

To separate the different SCSI units from each other, they are given a unique *SCSI Identification number* from 0-7. This number is used as an address on the SCSI bus. It is set on switches or straps on each device or card.

These rules must be followed when setting up the ID numbers on a SCSI bus:

| SCSI ID no. | Standard use                                            |
|-------------|---------------------------------------------------------|
| 0           | Main swapping device (system disk)                      |
| 1           | The (first) streamer tape drive. Free if no streamer    |
| 2           | The (first) magnetic tape drive. Free if no magtape     |
| 3           | Free                                                    |
| 4           | Free                                                    |
| 5           | Free                                                    |
| 6           | Free                                                    |
| 7           | Host computer (ND-100 SCSI adapter)                     |

If there are more ND-100 SCSI adaptors present, they should have the numbers 6, 5 etc.

# The Filestore Cabinet

## Overview

All mass storage units are mounted in a special filestore cabinet. This cabinet is shown in figure 2. The upper part of the cabinet is intended for a magnetic tape unit, and the lower part contains three shelves for magnetic or optical disks. One shelf may contain one optical or two magnetic disks.

```
  ___________
 /          /|
/__________/ |
|          | |
|   ____   | |
|  |    |  | |
|  |____|  | /
|__________|/
```

*Fig.2. The SCSI filestore cabinet.*

At the rear of the shelves, there are two cable guides with some flat cables. These are the connections to the SCSI bus. In an empty cabinet, these cables are connected to each other in one chain, where the SCSI bus from the CPU cabinet is connected at one end. At the other end, there can be a termination plug, or a SCSI cable to another filestore or CPU cabinet.

# SCSI Bus Configurations

The SCSI bus(es) in a filestore cabinet can be configured in many different ways. But to avoid "wild" configurations, you should use one of the three configurations in the following example.

## Example

These are the three standard configurations of a filestore cabinet containing:

- One magtape drive,
- One optical disk drive and
- Four 8" magnetic disk drives.

(If a position in the cabinet is empty, it is simply bypassed by connecting the SCSI cables to each other.)

## Configurations

```
╔═══════════╗    ╔═══════════╗    ╔═══════════╗

╟───────────╢    ╟───────────╢    ╟───────────╢
║ Optical   ║    ║ Optical   ║    ║           ║

╟───────────╢    ║ Magnetic  ║    ║           ║

║ disks     ║    ║           ║    ║           ║
╚═══════════╝    ╚═══════════╝    ╚═══════════╝
(1) One-bus     (2) Two-bus     (3) "Free"
configuration   configuration   configuration
```

### 1. One-bus Configuration

All devices are connected to the same SCSI bus. This is the normal configuration, and all new cabinets are configured this way. If no magtape unit is present, a flat cable connects the two cable guides directly.

### 2. Two-bus Configuration

The two cable guides are two separate SCSI buses. Note that optical disks can only be connected to the bus on the left side! (The magtape can, of course, be connected to either of them.)

### 3. "Free" Configuration

Here the cable guides and flat cables are completely removed from the cabinet. The devices are connected individually to, for example, an ND-100 SCSI adaptor each.

# Optical Disk Drive: Overview

The LD 1200 optical disk can be used both in SCSI and SMD environments. Use and setup is described in the manual "SINTRAN III K Release Information." Some points of interest:

- WORM (Write Once Read Many), non-erasable media.
- Removable, dual-sided disk. Must be turned around manually to access the other side.
- Storage capacity of 1 Gbyte on each side.

## 2: Define in S3-CONFIG

Enter the menu and set the adaptor and ID number for the new optical disk in the (Next) column, for the first unused optical disk.

## 3: Define in LOAD-MODE

Include the command

```
@DEFINE-MASS-STORAGE-UNIT <device name> <device unit> [<fixed=F/removable=R>] [<subunit>]
```

in LOAD-MODE. The device name can be DISC-OPTICAL-1 to DISC-OPTICAL-4 and should correspond to the definition in S3-CONFIG.

## 3: Take Down the System

Let the system supervisor take down the system.

Switch off the power on both the filestore and CPU cabinets.

### Instructions

1. **Mount the Rails**  
   Mount the rails (3) and (4) in the cabinet with four screws in each rail, as shown in figure 3.

2. **Drive Positioning**  
   While one person holds the drive in position, another person must fasten the drive to the rails with three screws on each side.

3. **Slide to Lock**  
   Slide the drive in until it is locked in position.

4. **SCSI-Bus Connection**  
   Separate the two SCSI-bus connectors at the left side behind the drive, and connect both of them to the drive.

5. **Connect Mains Cable**  
   Connect the mains cable to the nearest mains socket in the cabinet.

6. **Switch on the Drive**  
   Switch the drive on. The mains switch is located at the rear of the drive.

### Set SCSI ID-Number

Enclosed with the drive are 8 switch-caps numbered from 0 to 7. Choose the one with the number selected as SCSI ID-number, and put it on the second switch from the right as shown in fig. 4.

The rightmost switch is not used when the SCSI interface is used, and any of the free switch-caps can be fitted.

### Power Up

Switch on the power on the CPU cabinet and the filestore cabinet.

### Start the Optical Disk

Open the cartridge door as shown in figure 4 and install a cartridge. Press the Start/Stop switch and wait 3-4 minutes until the drive is ready.

# 8: Test and Verification

To verify that the installation is OK, go through this sequence:

**Diskette:** Test Programs for ND-100/110 (210523-G01 or later)  
**Detailed description:** Test Program Description for ND-100/110 (ND-30.005)

| Test program: | Command sequence: | Comments: |
|---------------|-------------------|-----------|
| SCSI-TV       | 1:LIST-DEVICES    | Make sure that: <br> • The new opt. disk is present. <br> • Adaptor and ID-number are as defined in step 2. <br> • All the other devices are present. |
|               | 2:SELECT-DEVICE <br> \<Host adaptor>\<SCSI ID no.\> | Select the new optical disk for test. |
|               | 3:RUN-DEVICE-TESTS,ALL-TESTS | Run all tests without error messages. |

If there are any problems in LIST-DEVICES, such as error messages or some of the devices are missing, the most usual reasons are:

- Breaks in the SCSI bus, i.e., bad connectors, open connectors and so on.
- Not a termination plug at both ends of the SCSI bus.
- Two devices with the same ID number.

If there are any other errors, refer to the manuals listed in section 2: Related Documentation.

# 9: System Startup

- Restart SINTRAN.
- Do a COLD-START to make the new definition in S3-CONFIG active.
- Enter S3-CONFIG and make sure that the new optical disk exists in the "Current" column.
