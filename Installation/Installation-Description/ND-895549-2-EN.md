## 1 Prerequisites

For communication in a COSMOS network, then XMSG (ND 210373) is sufficient. For communication in an OSI network where conformance at layers 1 to 5 is required, you will also need the ND OSI Transport Service (ND 211023). These products will have their own prerequisites depending on the underlying communication technology being used.

## 2 Conformance

This section describes how the product conforms to the Basic Connection Oriented Session Protocol standard defined in ISO 8327.

Release A00 of the ND OSI Session Service:
- can initiate a session connection by sending a CONNECT SPDU.
- can respond to a CONNECT SPDU by sending either an ACCEPT SPDU or a REFUSE SPDU.
- implements and follows all the procedures for the following functional units:
  - kernel FU
  - half-duplex FU
  - duplex FU
  - exceptions FU
  - activity management FU
- does not implement extended concatenation.
- does not implement segmenting.
- does not use the Transport expedited service.

## 3 Errors Known But Not Corrected

If a user starts more timers (directly or indirectly) than it requested at initialisation time, then it MAY cause OSScall or OSSwait to fail with status 19086.

## 4 INSTALLATION PROCEDURE

This section describes how to install the ND OSI Session Service version A00 on a Sintran III system. Sintran version K or later is necessary.

### 4.1 PREREQUISITES

Before starting to copy the product files from diskette, you should check that the user that is to contain the product files has sufficient space. The product requires 202 free pages and 15 free file entries. If files from an earlier version of the product already exist, then it is recommended that you delete them or rename them before the new version is installed.

The number of free pages available to a user is found by using the Sintran command:

```
@USER-STATISTICS <user name>,
```

If the user does not have enough space then more space can be allocated as follows:

- Log in as user SYSTEM, and type:

```
@GIVE-USER-SPACE <user name>,<number of pages>
```

## 4.2 Copying the Product Files to Mass Storage

This is achieved as follows.

- Log in as user SYSTEM

- Insert the diskette labelled 211061A00-XX-01D (double density diskette) or 211061A00-XX-01S (single density diskette) into a floppy drive and type:

  ```
  @ENTER-DIRECTORY 211061A00-XX-01,<device-name>,<unit>,
  ```

- When the directory has been entered successfully, start the installation program by typing:

  ```
  @(211061A00-XX-01:FLOPPY-USER)INSTALL
  ```

The program checks that the user name is SYSTEM, and then displays the prompt:

> Enter the user name to contain the product files (UTILITY): 

Type the name of the user that is to contain the installed product files, or just type J if the user UTILITY is to be used. The program will then ask:

> Do you want to replace an existing version? (Y/N):

Type Y if the product files already exist on the user name, and you want to replace them with the new version. The installation program will assume that enough free space and files exist. If you type N or J, the installation program will not delete any existing files, and will check that there is enough free space and files.

The installation program copies the product files from the floppy disc into the user space. It displays the names of the files that have been copied, and any errors that may occur. Finally, it releases the directory, displays a prompt to remind you to remove the floppy disc from the drive, and exits.

If you want to use the OSI Session Service for communication which is ISO conformant in layers 1-5, and so communicate with non-ND systems, you will also need the ND OSI Transport Service (ND 211023) and XMSG (ND 210373). For ND to ND communication, the OSI Session Service may be used over XMSG without the OSI Transport Service.
