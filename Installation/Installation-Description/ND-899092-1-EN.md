# Installation Description

## Product: Publisher 19" Display Unit w/Adapter Card
### For computer: ND PC and OWS

The first part of this description tells you how to install the adapter card, and how to connect the display unit to the workstation. The second part tells you how to make necessary changes in the workstation's software.

The installation procedures are identical for the ND-PC /286, OWS-55 and OWS-85. The drawings used here show the OWS-55. The internal organization of some components is different for the other models, but the procedures are the same.

## WARNING! Protect yourself! Avoid equipment damage

- Turn off the power and disconnect all cables including the power cable before removing the covers.
- If possible, wear a wriststrap connected to the computer chassis.
- The electronic parts are static-sensitive. Do not remove the card from its box until you are ready to install it. Always touch a metal part of the computer’s chassis before handling the card. Handle the cards by the edges and never touch the edge connectors or components directly.

## What do you need:

- The Publisher 19" display unit w/adapter card, ND 110567. There is also an optional tilt and swivel stand for the display unit, product number ND 110638.
- A Philips (crosshead) screwdriver.
- The SETUP and Test Diskette and the Enhanced MS-DOS 3.2 System Diskette that was delivered with your computer.
- If you have Windows installed, you will need your set of Microsoft® Windows diskettes. You must have Windows 2.0 or later.

## Installing the Adapter Card and Display Unit

1. First switch off the workstation, then disconnect all cables.

2. Place the system unit on a suitable table, where you have a neat, clean work area. If you have an OWS-85, be sure that it is unlocked.

3. Remove the screws holding the cover. Slide the cover towards the front, then lift it gently.

   ```
   +-------------------------+
   |                         |
   |                         |
   |    +----------+         |
   |    |          |         |
   |    |          |         |
   |    +----------+         |
   +-------------------------+
   ```

4. Choose a vacant 16-bit slot for the card.

5. Remove the corresponding blind cover.

   ```
   +------------+
   |            |
   |  Vacant    |
   |   Slot     |
   |            |
   +------------+
   ```

6. Put on the wriststrap (see instructions on the envelope it comes in) or touch a metal part of the computer with one hand to discharge static electricity.

7. Remove the adapter card from its plastic packing. Handle the card only by the edges.

   ```
   +-----------------+
   |                 |
   |                 |
   |  [illegible]    |
   |                 |
   +-----------------+
   ```

# Adapter Card Installation

## Jumper Settings

### On the Adapter Card

``` 
   -----
  |     |
  |  o  | JP1
  |     |
  -----
```

- If there is no jumper on JP1, insert one.

### If You Have an OWS-55 or ND PC/286

```
    O
J 12 | | | J 13
   ------
  |      |
  |      |
  ------
```

- On the CPU card (the leftmost card as seen from the front of the workstation), remove the jumper on J12.

### If You Have an OWS-85

```
   __ o
   |  |
 L |  |
 O |  | 
 R |  | 
  -----
```

- On the CPU card (the leftmost card as seen from the front of the workstation), move the jumper from COLOR to MONO setting.

## Adapter Card Replacement

9. Remove the old video adapter card. Take out the screw on the bracket (see drawing under next step), and pull the card upwards.

10. Align the new adapter card over the empty slot. Gently but firmly press the card down into the connector. Make sure that the tongue on the card's bracket fits into the slot in the bottom of the workstation chassis. If you find this difficult, take the card out and bend the tongue a little. Fasten the card.

```
    ________
   |        |
   |        |
   --------
```

11. Slide the cover back onto the workstation and fasten it with the screws.

```
   ________________
  | CAUTION!       |
  | Do NOT switch  |
  | on the         |
  | workstation    |
  | until all the  |
  | cables are     |
  | connected!     |
  ----------------
```

12. Connect the two cables that came with your display unit (signal cable and power cable) from the display unit to the system unit.

13. Re-connect all the other cables.

You are now finished with the hardware installation.

# Changing the Workstation's Software

**Note:**
Do not use any of the diskettes marked CORNERSTONE in this installation. They contain drivers for non ND applications.

1. Insert the SETUP and Test diskette into drive A.

2. Switch on the display unit, then switch on the workstation. Press F1 when you are asked to.

3. You will now have the System Setup menu on the screen. Press F1.

4. Use the arrow keys to move to the field for Video Display. Press F2 to get Monochrome Display Adapter if it is not already selected.

## Installation Instructions

### Steps to Install Windows

5. Remove the diskette from drive A, and press F5 only one time to store the settings. Do not press F5 again at this time, even if the screen says so!

6. Insert the Enhanced MS-DOS 3.2 System Diskette into drive A.

7. Press F5 to restart the workstation. Eventually, you will get the MS-DOS prompt A>

### Note
```
Read all the text in this step before you start installing Windows.
```

To be able to use this display unit together with Windows, you must reinstall Windows. Insert the Windows setup diskette (number 1) into drive A, and type:

```
A:\> 
SETUP ↲
```

Follow the instructions on the screen.

- After some steps, you will be asked to select your Display Adapter, press the down-arrow key and scroll the list until Other is highlighted (you will have to scroll the list to see Other).
- Press ↲

- Insert the Drivers ND diskette (which came with your display unit package) into drive A.

- Press ↲

- Use the down-arrow key to move to DualPage Card with 19 inch Display.

- Press ↲

- Continue the setup procedure. After some steps, you will be asked to select the System font. Use the down-arrow key to move to Other.

- Press ↲ two times.

- Use the down-arrow key to move to System (Set #4)

- Press ↲.

- When you are asked to select the Terminal (OEM) font, use the down-arrow key to move to Other.

- Press ↲ two times.

### Additional Steps

- Use the down-arrow key to move to Terminal (Set #4).
- Press ↲.
- Insert the Windows diskette number 1.
- Press ↲ and continue as instructed on the screen until the Windows installation is completed.
- Remove Windows diskette number 3 from drive A and press CTRL + ALT + DEL (press and hold CTRL and ALT, then press DEL) to restart your workstation.
- Go out of Windows by pressing ALT + F4 several times until you have the DOS prompt on your screen.

If you have neither DTM nor NOTIS-WP installed, your installation is now finished! If you have DTM installed, continue with step 9.

9. Find DTM-diskette number 1 (of two) that came with your display unit package. Do NOT use the DTM-disks that originally followed your computer. Insert the diskette into drive A and type:

```
A:\> 
INSTALL ↲
```

10. When you get the Display Unit Selection screen, use the down-arrow key to move to ND 19" High Resolution Black & White Display Unit.

11. Press ↲

12. To select keyboard language, use the down-arrow key to move to the keyboard language you are using.

13. Press ↲

14. In the Disk Drive selection menu, select the hard disk where you want to install DTM. This will usually be drive C. To select drive C, press the down-arrow key once, and press ↲.

## Installation Steps

15. Now select installation method. If you have ND-applications installed, and do not want to reinstall them, select **Install from floppy disk - do NOT delete** and press `J`.

   If you, on the other hand, want to delete all your existing DTM files before installing the new ones, press the down-arrow key once to select **Delete existing DTM then reinstall from floppy disk** and press `J`.  
   This might require reinstallation of your ND-applications.

16. Now comes the file-copy part of the installation. Just follow the instructions on the screen until you get the **Final message** screen. Do not restart the computer now even if you are told to, just press `J`!

   Continue with step 17 if you have NOTIS-WP installed. If not, go directly to step 18.

17. Insert the **Drivers ND-diskette** (which followed your display unit package) into drive A and type:
   ```
   A:J
   INSTALL J
   ```

18. When this installation program is finished, remove the diskette from drive A and press `CTRL + ALT + DEL` (press and hold CTRL and ALT, then press DEL) to restart your workstation.

   **The installation is now finished!**
