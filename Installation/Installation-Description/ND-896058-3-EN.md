## Page 1

# Error Correction Diskette for ND TPServer C01 - 211560

**BEFORE YOU START THE INSTALLATION - PLEASE READ THIS!**

The enclosed diskette contains one important patch for SINTRAN and a new revision of the swapper.

## Error Corrections and Changes Included on the Correction Diskette:

**Swapper M03**
- Better consistency in handling disk transfer conflicts (Fatal 554B)
- Larger trace buffers
- Better information collection regarding fatal error 40B

**SINTRAN III/VSX-N Patch 044B**
- Two locations in COMMON overwritten. Could lead to several unpredictable errors

## Installation Procedure:

- When you have finished step **3** in the installation procedure for 211560, insert the floppy in one of the floppy units and enter it.

- Copy the file `(COMMA:SYSTEM) INSTALL-ADDON` to user SYSTEM.

- Perform the command `@MODE INSTALL-ADDON *INSTALL-ADDON:OUT*`

- If the job finishes successfully, the message `COPY FINISHED - Everything OK` will be displayed.

- If a message with `'SERIOUS ERROR'` in it occurs, please check the output file for further error messages.

- Proceed with step **4** in the installation procedure for 211560.

# Installation Description for ND TPServer (C01)
## PACK-BASIC & PACK-MAIN

1. Copy PACK-BASIC and PACK-MAIN from streamer using DISK RESTORE.

2. Start the machine and wait for the message SYSTEM IS AVAILABLE and log in with the Sintran user SYSTEM and password ND.

3. Do the following:
   - If the machine is not equipped with CPU number PROM you have to patch it in SINTRAN.
   - Edit the file `(MODE-FILES)DEF-XMSG-LOCAL:MODE` and run it.
   - Edit the file `(MODE-FILES)DEF-XMSG-NET:MODE` og kjør den
   - Edit the S3-CONFIG (important is First legal physical page for device buffer)
   - AIP-CONFIG:SYMB (right slotnumber and IP-addresses)
   - Copy the right ND5000 MICROPROGRAM to control-store:data and delete microprograms not needed.
   - SOFTICE (define all softice keys)
   - Edit the file `(ND-OPERATION)SW-CONFIG:SYMB` with the right machine name.
   - DP-SERVICE (define the devices on the DOMINO SCSI bus)
   - Edit the file `(MODE-FILES)START-ND5000:MODE` to match your memory size.
   - Edit the file `(MODE-FILES)INIT-RAM:MODE` if RAM disc are to be used.
   - Copy your old USER ENVIRONMENT databse to the user UE-DATABASE-USER or make a new database.
     - Remember that the database must have the following users defined `(SYSTEM,MULTI-OE,SIBAS-MANAGER,SERVERS)`.
     - Remember that the users MULTI-OE and SERVCERS must be defined with "SERVER" access.
   - Run the program `(USER-ENVIRONMENT)UE-CHCPU` (old cpunumber is 20636)

4. Do the command `@RESTART-SYSTEM` and the system will automatically do a COLD-START.
