# Installation Description

**Product name:** NOTIS-WP for ND-WS  
**Product number:** ND 230022N

## Before you start:

- DTM version C must be installed.
- There must be at least 1.9 Mbyte free disk space on the same disk as DTM is installed.
- You should only install NOTIS-WP with the same language as DTM.
- If you reinstall DTM, you may have to reinstall NOTIS-WP also.
- The installation procedure needs to know what kind of monitor you have: EGA, VGA or Wyse 700 B/W. If you change to a different type of monitor, you should reinstall NOTIS-WP.

## How to Install

1. Close all Windows applications. The installation program is not a Windows application. Put the installation diskette, with the correct language, in drive A.
   
2. At the DOS prompt, type:
   ```
   A:INSTALL ↵
   ```

3. Answer all questions with numbers, and insert the program diskette when asked for it.

4. The installation program inserts NOTIS-WP as an application under DTM, and copies in the necessary system files.

5. Remove the diskette from the drive.

6. Press CTRL+ALT+DEL to restart the OWS with DTM after installation.

7. If you want NOTIS-WP to work differently from the default, change all values and press ↵. WP will then fetch the init file each time you start NOTIS-WP.
