# ND-5000 COMPUTER SYSTEMS

## Introduction

Norsk Data's ND-5000 series of computers is one of the most advanced 32-bit super minicomputer systems available. It accommodates exceedingly large programs and data areas, and fulfills the requirements imposed by most ADP and technical/scientific applications.

## Features

- Advanced instruction repertoire
- Multiport memory system
- SINTRAN III operating system
- Multiprogramming capacity
- Highly advanced processor technology
- BCD Arithmetic

## Product Description

The ND-5000 series consists of the ND-5700, ND-5800, and ND-5900 systems. The ND-5900 system is a multiprocessor system which is available in three models: model 2 (two-CPU), model 3 (three-CPU), and model 4 (four-CPU). Each system is more powerful than the one that precedes it, and any system can be upgraded to a higher-performing system.

The ND-5000 systems are housed in one cabinet. They are based on the ND-5000 32-bit CPU and include the memory system, the ND-110/CX front-end processor, the I/O system, and SINTRAN III operating system.

Basic configuration for these systems includes from 10 to 20 MB memory, a disk controller, a 12 MB floppy disk unit with controller, a console hardcopy terminal, and the SINTRAN III operating system and the utility software. Any disk system from 70 MB and up may be added in accordance with the configuration rules.

Off-line operator interaction with the computer is facilitated by the Control Panel. The panel consists of status indicators, a security lock, and indicators that show CPU and Cache memory utilisation. The Telefix adaptor for remote diagnostics is also built in, plus a printer outlet for hard-copy output of Telefix communication.

The individual characteristics of each system within the ND-5000 series are given below.

## System Architecture

The ND-5000 series is based on a tightly-coupled multiprocessor design built around a high-speed multiport bus system. The implementation is based on one or more 32-bit CPUs (ND-5000) which handle the main program execution, and one 16-bit front-end processor (ND-110/CX) which performs interrupt handling and maintenance tasks. The main CPU is directly connected to the bus system, while the front-end processor is connected to this bus system via ports.

The bus system, called multifunction bus, has a capacity of 18 MB/sec and has connection support for the main CPUs, memory modules, and the I/O devices. In addition, one or more I/O / DMA buses can be connected to this bus system via ports. Special devices, such as array processors, can also be connected directly to the bus system.

The main memory is shared between the main CPU(s) and the front-end processor. Up to 512 MB of main memory can be configured. In addition, the front-end processor has its own local memory (up to 32 MB) where part of the operating system is kept.

## Main Features

- The ND-5000 processor is based on the latest CMOS gate-array hardware. These semi custom-designed chips provide for higher speed and compact packaging. The basic cycle time of this processor is 70 nanoseconds. Many instructions execute to completion within this period.

- Integral four-level pipeline system allows for simultaneous processing of instructions.

- A memory management system allows each user an address space of up to 4.3 gigabytes for programs, and up to 4.3 gigabytes for data. This allows large files to be accessed as if they were arrays. Thus, the hardware memory management system accesses data rather than the more resource-consuming file system.

- Large and modular cache system, referenced by logical addresses. The cache is divided into two parts: Instruction and Data. The instruction cache holds up to 8K of decoded instructions with up to 40 bytes width (320 KB total). A so-called "write once" cache strategy is implemented in the ND-5000 processor, which reduces the memory write delay drastically and improves system performance. 64 KBytes of cache memory is also available for data. Cache maintains a high hit-rate, even with shared-code programs.

- Microcoded instruction set with variable length instructions with operand types including bit, byte, half-length, full-length, and double-length words.

- Byte-oriented instruction sets which are tailored for high-level program execution efficiency such as FORTRAN DO loops and COBOL string handling.

- The 32-bit CPU, which may be shared by many programs via the virtual memory system and the SINTRAN III Operating System. Context-switching routines are implemented in the microcode.

- A multiport memory system which allows direct access from memory to the CPU, the Front-End Processing unit, the DMA devices, and the communication links (MEGALINK, HDLC).

- The Operating System – Norsk Data's interactive, terminal-oriented SINTRAN III. It allows many programs, written in different languages, to be executed simultaneously. Real-time tasks, local and remote batch jobs, and data communication may also run concurrently with the time-sharing users.

- Special instructions for stack and frame handling in block-structured languages.

- Full BCD arithmetic and conversion microcode with hardware support gives high-speed COBOL processing.

- Fast floating-point processor, based on full custom-designed VLSI, gives most results in 0.2-0.3 micro-seconds. This provides 32-bit single precision floating-point operations with a 23-bit mantissa and a 9-bit exponent. For 64-bit operations, the mantissa is 55 bits long.

## Expansion Possibilities

There are 13 free I/O slots in the basic system for peripheral controllers and interfaces. Any of the ND-100 system peripherals may be attached.

Of each system's memory, 4 (2 in ND 5700) megabyte is local for the ND-110/CK Front-End Processing Unit. The remaining memory is common to both the ND-5000 CPU and the ND-110/CK processor. Up to 300 MB of shared memory is available within the ND-5000 system cabinet. More memory (up to 512 MB) is available using extra expansion cabinet.

If more memory or I/O interfaces are needed, an expansion rack may be added to the second cabinet. This system includes one I/O DMA channel, and it can be extended to up to three I/O DMA channels.
