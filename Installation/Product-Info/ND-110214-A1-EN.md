## Page 2

# ND TEMPEST ASYNCHRONOUS DISPLAY TERMINAL

## Introduction

Tempest declaration is today a prerequisite for terminals used in top security applications in the defence and government sectors.

Norsk Data offers Tempest-declared terminals which are at the same time user friendly, ergonomically correctly designed, and built to integrate well with Norsk Data’s Office Automation and ADP applications.

The ND Tempest terminals are designed to give special support to such ADP applications as word processing, screen handling etc. Special function keys speed up and simplify input of commands to the system.

The position and angle of the terminals can be adjusted to suit each individual user. The screen can be swivelled and tilted to cut out interference from windows and overhead lighting.

The screen is treated to minimise reflection and the display colour is chosen to reduce eye strain. The screen shows a flicker-free display of up to 30 lines of 80 characters. Each character is formed in an 11 x 14 point matrix giving high resolution. Special applications may be able to utilise a feature in the terminal giving 30 lines of up to 132 characters per line with a character cell of a 7 x 14 points matrix. Both uppercase and lowercase characters are provided, with a full character set for each national language. Blink, underline and inverse display are all included as standard features. The keyboard is a full NOTIS keyboard, allowing the use of the integrated NOTIS office support products. The keyboard is separate from the display, and the terminals are simple, pleasant and comfortable to work with.

## Product Description

The ND 110214 Tempest Asynchronous Terminal is designed to meet the Tempest requirements of NACSIM 5100A and AMSG720B. In line with modern practice, all electrical interfaces to the host ND minicomputer have been replaced by fibre optic alternatives. Provisions are made for sealing the enclosures, and a special cover plate is provided to give tamper protection to the fibre optic and keyboard connectors.

The terminals are produced in UK, Swedish and Norwegian versions. The terminals are intended to be used for Norsk Data’s interactive systems, for text as well as for data processing. PUSH-key functions for sixteen user-programmed character strings are provided. The user can program recurring words or code sequences. Instead of typing these again and again, the operator simply touches the appropriate PUSH-key.

## Features

- Tempest-shielded screen and keyboard
- Optical interfacing and cabling between CPU and terminal.
- The terminal is delivered with a TDV 2200/9 NOTIS-compatible emulator.
- 15° screen with bonded anti-reflex faceplate
- Uppercase and lowercase characters including line drawing, histogram, numeric subscript/superscript, Greek letters and plot characters
- Insert, delete, copy, underline, move and erase functions
- 16 PUSH-keys allowing commonly used words or control strings to be transmitted by pushing a single key. The strings associated with PUSH-keys are stored in non-volatile memory and are not lost when power is turned off.
- All switches reside in non-volatile memory ensuring simple setup. Setting up is done using self-explanatory menus
- The terminals are especially prepared for full-screen editing support; for example applications such as NOTIS Word Processor, ACCESS Query Language and FOCUS Screen Handling
- Green characters on black background, or inverse.

## Specifications

### Power Input
- 230 volts +- 15% or 115 VAC +- 15% 47 to 440 Hz
- 160 VA approx.
- Heat output 90 watts approx.

### Environmental Parameters
- Operating temp: 0-35 degrees C
- Relative humidity: 0-90% Non condensing

### Interfaces
- Fibre optic interfaces to the terminal ports are provided through 9mm SMA connectors giving a range up to 1 kilometre provided that absolutely high-quality fibre optic cables are used for connections to the ND minicomputer.

### Dimensions

|           | Terminal | Keyboard |
|-----------|----------|----------|
| Height    | 390      | 45       |
| Width     | 360      | 516      |
| Depth     | 405      | 220      |

### Display Characteristics

- **CRT**: 15" diagonal with bonded anti-reflex faceplate
- **Display memory**: Dual-port 256 Kb. Displayed characters require 16 bits each. The memory can be used for characters, packed characters, variables, buffer space and graphics.
- **Characters per line**: 80 or 132 (132 characters mode not used by ND software)
- **Number of lines**: 30
- **Character cell**: 11 by 14 with 80 characters per line. (7 by 14 with 132 characters per line.)
- **Character set**: NOTIS character set. Full uppercase and lowercase character sets are available in Norwegian, Swedish and UK. All standard sets contain Teletex set semigraphic characters for line drawing, histogram plotting and numeric subscript, as well as Greek letters and mathematical symbols.
- **Attribute handling**: In addition to the TDV 2115 compatible attribute handling the terminal can handle the following attributes via the SGR command: Normal, Low video, Underlining, Blink, Inverse video

### Graphics Resolution
- The graphics mode is Tektronix 4010 compatible. Two superimposed planes of 640 by 480 points are available. Can be used with NOTIS-BG and NOTIS-DRAW.

### Refresh Rate
- 61 Hz

### Microprocessor
- Zilog Z8001

### Program Memory
- PROM: 128Kb
- RAM: 128Kb
- EPROM: 2Kb

### Keyboard
- Full NOTIS keyboard

### Cursor
- Underline, blinking and steady block cursor are softswitch selectable

### Cursor Control
- Cursor right
- Cursor left
- Cursor up
- Cursor down
- Cursor home
- Direct cursor positioning

### Scroll Control
- Scroll up
- Scroll down
- Smooth or step scroll is selectable by softswitch

### Tab Functions
- Horizontal tab.
- Backward horizontal tab.
- Horizontal tab. set
- Horizontal tab. clear
- Clear all tabs.

### Editing Functions
- Insert character. Insert line.
- Delete character. Delete line.
- Erase character, line, screen.

### Softswitch Control
- Set mode
- Reset mode

These control functions allow a number of the softswitches to be controlled remotely without affecting the setting at the next power-on.

### PUSH-key Loading
- 16 PUSH-key strings can be loaded from the host computer
