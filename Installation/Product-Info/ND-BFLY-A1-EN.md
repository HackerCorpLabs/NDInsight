# ND-BUTTERFLY Office Workstations 10, 11 and 12

## Product Overview

The ND-BUTTERFLY OWS (office workstation) series is a range of powerful workstations, aimed at giving the user sufficient processing power to handle advanced office word processors and decision-support applications.

The ND-BUTTERFLY OWS comes with the Microsoft(TM) MS-DOS operating system and the MS-WINDOWS graphic interface. The latter is very user-friendly and includes a set of convenient desktop applications, such as Calculator, Notepad, Calendar, and Card file.

The ND DeskTop Manager (DTM) is an entirely new user program for the Butterfly Workstations, providing the NOTIS-WP functions on a personal computer. This NOTIS workstation word-processor (NOTIS-WSWP) can read and write text documents from several sources: NOTIS Document Server on a host ND computer, the SINTRAN file system on an ND-100 or ND-500 computer, or files stored on a local MS-DOS disk.

A terminal-emulator function allows the workstation to perform tasks with the ND-NOTIS and ND-DIALOGUE product families, making full use of the screen-handling and keyboard functions for increased productivity. A file-transfer function makes information stored on the host computer available to programs in the MS-DOS environment, and vice versa.

The keyboard has labelled function keys, separate numeric and cursor keypads, and programmable pushkeys. It is compatible with most IBM applications. The keyboard is equipped with a mouse pointing device, greatly enhancing user efficiency in many applications. The mouse may be moved on any desk area, and its three keys may be programmed to send any code sequence required. The PC function keys (F1 to F10) have been moved to the right-hand side, which many users find more convenient. The pushkeys may store recurrent commands, program names, and phrases.

The screen is a 14" enhanced colour display with EGA (Enhanced Graphic Adaptor) interface, giving high resolution of 640 x 350 pixels with 16 colours from a palette of 64. The EGA interface is standard in the system unit, giving compatibility to different graphics standards. A 14" monochrome black-on-white monitor is also available.

The system unit is based on the Intel 80286 microprocessor, running at 8Mhz, with 512 Kb random access memory (RAM). The system unit has room for three half-height storage modules: 1.2 Mb floppy-disk unit, 40 Mb hard-disk unit, or combinations hereof. The floppy-disk unit can read 360 Kb diskettes produced on other IBM-compatible systems.

A wide set of peripherals may be connected, including printer, expansion board for memory, additional storage devices, communication, floor stand for the system unit, and desktop arm for the monitor.

# ND-BUTTERFLY Office Workstation 110

## Product Overview

The ND-BUTTERFLY OWS-110 is a new implementation of the ND-100 16-bit minicomputer, together with the Intel 80286 CPU, in a size suitable to be placed on the user's desk. This ND-110/PCX CPU is fully compatible with earlier models in the ND-100 range, and runs the SINTRAN operating system and other ND software.

The CPU, located within a popular personal computer, occupies one slot. In addition to the CPU itself, the board contains 1Mb of memory (RAM) expandable to 2Mb, the virtual memory management system of the ND-110/CX, and a serial port.

In addition to the ND-110/PCX CPU, the system unit includes the Intel 80286 microprocessor, acting as an input/output controller, handling disks and peripherals for both processors. The Intel 80286 runs the MS-DOS 3.1 operating system in cooperation with the SINTRAN operating system.

A special version of the User Environment menu-system has been adapted to be used with the ND-BUTTERFLY OWS-110.

NOTIS-WP together with the user interface part of NOTIS-DS (Document Storage) and NOTIS-ID (Information Distribution) are delivered as standard with the ND-BUTTERFLY OWS-110. The DS and ID database is stored on an ND-100 or ND-500 host computer.

The MS-DOS 3.1 operating system running on the Intel 80286 is delivered with the system, including MS-WINDOWS and Desktop Application Package. A file-exchange function is embedded in the ND version of the MD-DOS, allowing files to be accessed from either environment.

The keyboard and the monitor are the same as for the ND-BUTTERFLY range, giving ND-NOTIS functionality with IBM compatibility.

A wide range of peripheral options are available, including printer, plotter, expansion board for memory, additional storage devices, communications, floor stand for the system unit, and desktop arm for the monitor.

### Product Overview

The ND-OWS Entry Kit consists of the ND-NOTIS keyboard for ND-BUTTERFLY OWS and the software package ND DeskTop Manager. ## ND-BUTTERFLY Teamstation

### Product Overview

The top of the ND-BUTTERFLY range is a minicomputer, based on the OWS-110. It allows the connection of up to four additional terminals that can run the SINTRAN operating system in time-sharing mode.

The terminals may be standard NOTIS-TDV or NOTIS-TWIST with asynchronous communication, or ND-BUTTERFLY OWS 10, 11 or 12. The terminal may run any SINTRAN program, whereas the workstations can run MS-DOS locally and SINTRAN tasks through the communication facilities.
