# Hardware Terminals

## ND 248 Word- and Data-Processing Terminal

The ND 248 is an especially tailored version of FACIT's 4420 terminal. It is supplied and sold exclusively by Norsk Data A.S.

The ND 248 has an ergonomic design and is pleasant both to look at and to use. It satisfies state-of-the-art design criteria for an office and data processing terminal, both regarding its physical characteristics and in the functional layout of its keyboard.

### Features

- A full NOTIS Text and Information Processing terminal
- British, French, German, Norwegian, Swedish and Danish versions
- Full NOTIS semi graphic character set
- Ergonomic and pleasant design
- Separate keyboard with integral wrist rest
- State-of-the-art keyboard layout
- Numeric key pad
- Cursor control key pad
- Full set of editing and control keys for Word Processing
- Free positioning, swivel and tilt of screen
- 12" green phosphor screen
- Crisp, clear characters with true descenders
- Diagnostics mode

### Terminal Adjustments

The advanced mechanical design of the ND 248 terminal allows the user full freedom of both positioning and viewing angle adjustment. Users may first choose their preferred working posture, thereafter adjust the terminal by tilting, swivelling and free movement.

### The Keyboard

The keyboard is connected to the screen by a flexible cable, allowing the independent positioning of screen and keyboard. The keyboard has a low profile and includes an integral wrist rest.

The ND 248 keyboard is a superset of a standard ASCII keyboard. In addition to the ASCII set, the keyboard includes a separate numeric pad, a cursor control block and word processing keys.

# Interface

The ND 248 terminal is supplied with both current loop and RS 232 C interfaces. Speeds from 300 to 9600 bps (30 to 1000 characters per second) full duplex may be used. XON/XOFF is switch settable if required.

# Local Printer

The local printer interface is included in the ND 248 terminal. It is an RS 232 C interface with speed range from 300 to 19,200 bits/sec.

# Character Sets

The terminal is available in British, French, German, Norwegian, Swedish and Danish versions. It contains the full semi-graphic set used by the ND NOTIS products.

# Screen

The ND 248 terminal has a 12", non-glare, green phosphor screen. Information is presented in a crisp and clear manner, in order to maximise legibility and user comfort and to minimise eye strain, even under difficult lighting conditions.
