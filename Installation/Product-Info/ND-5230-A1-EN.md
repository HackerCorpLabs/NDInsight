## Introduction

The ND-5000 Extended Server (ES) model L represents a range of powerful, flexible systems that are suited to function either as servers in an open network or as stand-alone systems in medium to large organizations. The network support facilities and the configuration flexibility provided by these systems make them ideal for use as servers in a network of workstations and PCs. In addition, each system can be fully configured with mass-storage and backup devices, terminals and PCs, and applications to allow it to function as a stand-alone system in an organisation.

The other models in the ND-5000 ES series are models S and C. These two models provide entry-level small systems and medium-size departmental servers.

The ND-5000 ES model L consists of eight systems which cover a wide performance range.

The ND-5000 ES model L runs a wide variety of applications from Norsk Data and other software development houses.

## Features

- Powerful, flexible system for managing computational tasks.
- Well suited as a server in a local or wide area network.
- Large performance range.
- Up to 35 GB disk capacity.
- Up to 300 MB memory in the system cabinet.
- SINTRAN III operating system.
- Full upgrade possibility within the model range.

## Product Description

The ND-5000 ES model L series consists of six systems which cover a wide performance range. ND-5200, ND-5400, ND-5500, ND-5700 and ND-5800 ES are single-CPU systems. The ND-5900 ES system is a multi-CPU system which is available in three models: model L2 (two-CPU), model L3 (three-CPU) and model L4 (four-CPU). Each system is more powerful than the one that precedes it; and any system can be upgraded to a higher performing system.

The ND-5000 systems are housed in one cabinet. They are based on the ND-5000/32-bit CPU, and include the memory system, the ND-120/CX (ND-120 in ND-5200, ND-5400 and ND-5500 systems) front-end processor, the I/O system and SINTRAN III operating system.

Basic configuration for these systems includes from 6 to 30 MB memory, an SCSI or SMS disk interface, a 12 MB floppy-disk unit with controller, a console hardcopy terminal and the SINTRAN III operating system and the utility software. Any disk system from 70 MB and up may be added in accordance with the configuration rules.

Off-line operator interaction with the computer is facilitated by the Control Panel indicators. The panel consists of status indicators, a security lock, and indicators that show CPU and Cache memory utilisation. The Telefix adaptor for remote diagnostics is also built in, plus a printer outlet for hardcopy output of Telefix communication.

## Expansion Possibilities

There are 14 free I/O slots in the basic system for peripheral controllers and interfaces. In addition, there are 17 free slots for memory and intelligent disk and communication controllers.

Up to 300 MB of shared memory is available within the ND-5000 system cabinet. More memory (up to 512 MB) is available using an extra expansion cabinet.

If more memory or I/O interfaces are needed, an expansion rack may be added to the second cabinet. This system has one I/O DMA channel, and it can be extended to include up to 3 I/O DMA channels to provide faster I/O.

## System Architecture

The ND-5000 ES model L is based on a tightly-coupled multiprocessor design, built around a high-speed multiport bus system. The implementation is based on one or more 32-bit CPUs (ND-5000) which handle the main calculation and program execution, and one 16-bit front-end processor (ND-120/CX or ND-120) which performs interrupt handling and maintenance tasks. The main CPU is directly connected to the bus system, while the front-end processor is connected to this bus system via ports.

The bus system, called multifunction bus, has a capacity of 18 MB/sec and has connection support for the main CPUs, memory modules and the I/O devices. In addition, one or more I/O / DMA buses can be connected to this bus system via ports. Special devices, such as array processors, can also be connected directly to the bus system.

The main memory is shared between the main CPU(s) and the front-end processor. Up to 512 MB of main memory can be configured. In addition, the front-end processor has its own local memory (up to 32 MB) where part of the operating system is kept.

The main features of the ND-5000 ES model L are:

- The ND-5000 processor is based on the latest CMOS gate-array hardware. These semi-custom-designed chips provide for higher speed and compact packaging.
- Integral four-level pipeline system allows for simultaneous processing of instructions.
- A memory-management system allows each user an address space of up to 4.3 gigabytes for programs, and up to 4.3 gigabytes for data. This allows large files to be accessed as if they were arrays. Thus, the hardware memory-management system accesses data rather than the more resource-consuming file system.
- Large and modular cache system, referenced by logical addresses. The cache is divided into two parts: instruction and data. The instruction cache holds up to 8K of decoded instructions with up to 40 bytes width (320 KB total). Implemented in the ND-5000 processor is a so-called write once cache strategy which drastically reduces the memory write delay and improves system performance. 64 KBytes of cache memory is also available for data. Cache maintains a high hit-rate, even with shared-code programs.
- Micro-coded instruction-set with variable length instructions, with operand types including bit, byte and half, full and double-length words.
- Byte-oriented instruction sets which are tailored for high-level program execution efficiency such as FORTRAN DO loops and COBOL string handling.
- The 32-bit CPU, which may be shared by many programs via the virtual memory system and the SINTRAN III operating system. Context-switching routines are implemented in the microcode.
- A multiport memory system which allows direct access from memory to the CPU, the Front-End Processing unit, the DMA devices and the communication links (MEGALINK, HDLC, Ethernet).

## Features

- The operating system - Norsk Data’s interactive, terminal-oriented SINTRAN III. It allows many programs, written in different languages, to be executed simultaneously. Real-time tasks, local and remote batch jobs, and data communication may also run concurrently with the time-sharing users.
- Special instructions for stack and frame handling in block-structured languages.
- Full BCD arithmetic and conversion microcode with hardware support gives high-speed COBOL processing.
- Fast floating-point processor, based on full custom-designed VLSI, gives most results in 0.2-0.3 microseconds. This provides 32-bit single precision floating-point operations with a 23-bit mantissa and a 9-bit exponent. For 64-bit operations, the mantissa is 55 bits long.

# Software

The basic configuration of all ND-5000 ES model L systems include the SINTRAN and the utility software package. This package includes the SINTRAN operating system, accounting system, Operator Environment software (including among other things ND Backup Manager and ND Sprint spooling system), User Environment, test programs and other utility programs.

In addition, a wide variety of ND applications and basic software is available on ND-5000 ES model L:

- Communications software. Communication between ND systems and between ND and other vendors’ systems.
- Terminal emulators, remote job entry and terminal concentrators.
- A wide variety of compilers and programming languages.
- Database systems.
- Development tools and editors.
- Information and Administrative Data Processing (ADP) tools.
