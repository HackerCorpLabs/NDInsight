# 450 MB 9" FIXED STORAGE DRIVE

## Introduction

The ND 106150 Fixed Storage Drive is a sealed-module, 9-inch rigid disk drive that uses state-of-the-art "thin-film" head technology. The ND 106150 provides 450 Megabytes of formatted storage. The drive's characteristics include an average seek time of 18 milliseconds and a power consumption of approximately 250 watts. A directly coupled, DC brushless drive motor and universal power supply permit worldwide use of the ND 106150 disk drive.

## Features

- 18 milliseconds average seek time
- Fast SMD controller compatibility
- Automatic carriage and spindle lock
- High-performance linear actuator
- Daisy-chain interface compatibility
- UL, CSA, VDE standards
- Fixed or variable sectoring
- Rack mountable
- Low maintenance cost
- Good MBFB figures
- Phase-locked data separation
- Dual-channel capability
- FCC Class A compliance
- Selectable address

## Product Description

The ND 106150 consists of seven disks in a sealed module, a directly coupled DC brushless motor with digital speed control, linear actuator, universal power supply and DC cooling fan. The logic package uses low-power Schottky I²L, ECL and LSI technology. All read/write, fault transmitter/receiver and microprocessor-controlled servo electronics are contained within the logic package.

## Prerequisites
- ND 106320 15 MHz disk controller
- A Filestore cabinet, large or compact type for mounting of the disk drive.

## Technical Specifications

| Specification                  | Details                                      |
|-------------------------------|----------------------------------------------|
| Formatted capacity            | 450 Mb                                       |
| Number of disks               | 7                                            |
| Data surfaces                 | 12                                           |
| Data heads                    | 24                                           |
| Transfer rate                 | 14.52 MHz                                    |
| Spindle speed                 | 3,600 r/min                                  |
| Average rotational latency    | 8.33 ms                                      |

**Recording:**

- **Bits per inch:** 15,185
- **Tracks per inch:** 960
- **Recording method:** NRZ to RLL 2.7 data conversion

**Access time:**

- *Full stroke:* 45 ms
- *Average:* 18 ms
- *Track-to-track:* 5 ms

**Data Reliability:**

| Type                             | Errors                                        |
|----------------------------------|-----------------------------------------------|
| Recoverable read errors          | Less than 1 in 10^10 bits transferred         |
| Unrecoverable read errors        | Less than 1 in 10^12 bits transferred         |
| Seek errors                      | Less than 1 in 10^8 bits transferred          |

**Power:**

- **AC:** 120, 220, 230, and 240 V 50 or 60 Hz
- **DC:** ±5 V logic, ±24 V control addressing, +40 V spindle motor

- **Power dissipation:** Approx. 250 W
- **Operating temperature:** 10°C to 45°C
- **Operating humidity:** 20% to 80%

**Physical characteristics:**

| Dimension         | Measurement                              |
|-------------------|------------------------------------------|
| Height            | 259 mm                                   |
| Width             | 216 mm                                   |
| Length            | 750.6 mm                                 |
| Weight            | 30 kg [36 Kg with power supply]          |
