## ND 950 ND-SATELLITE/5
## ND 951 ND-SATELLITE/9

The ND-SATELLITE/5 and ND-SATELLITE/9 are both compact minicomputers based on the mature ND-100 design and technology.

The design criteria for the newest computers in the ND range were:

I. That the computer should have the power and flexibility to satisfy the needs of today's users in the fields of administrative data processing, text and information processing and scientific and technical data processing.

II. That the computer system should be a suitable satellite computer to both large ND-500 and ND-100 systems.

III. That the computer should be both small enough and quiet enough to satisfy current and future demands on equipment placed within a normal office environment.

The ND-SATELLITE/5 and ND-SATELLITE/9 minicomputers satisfy each of these criteria and many more.

# ND-SATELLITE Software Options

Each ND-SATELLITE is supplied with all necessary operating system and utility software and documentation. This is accompanied by ND's powerful Word Processing software – NOTIS-WP – consisting of the full screen text editor (TED) and the text formatter (TEX).

In addition, a range of software options are offered:

1. **Scientific/Technical Program Development Option**

   Compilers and runtime systems for FORTRAN, BASIC, PASCAL (ISO 80) and PED fullscreen Program Editor.

2. **Commercial Program Development Option**

   COBOL (ANS 74) Compiler and runtime system, including the ND SORT/MERGE package and the ISAM Index Sequential File Access package. PED fullscreen Program Editor.

3. **ACCESS Level 1 Option**

   ACCESS level 1 query-by-example database query and update system. ISAM Index Sequential File Access Option.

4. **DES-II Option**

   This is only available on ND-SATELLITE/9 Systems. The DES-II Data Entry System is an advanced data-entry system which may also be used as a card-punch compatible system. Up to 8 terminals may input data simultaneously.

5. **SORT/MERGE Option**

   The ND-SORT/MERGE package is available as an option in addition to the above software «packages».

ND-SATELLITE's communications with one or two remote ND systems is provided for by ND's ND-NET communications system and one or two high speed communications interfaces (HDLC). The physical connection may be a special cable (up to about 100 metres), or a public or private telephone line and modems.

If communication with another manufacturer's computer is required, options are available for remote job entry to and on-line dialog with IBM, Honeywell, CDC and Unisys computers.

Up to two communications interfaces are available. Each may be used either towards another ND system or to a mainframe.

## Use

Programs, e.g. compilers, editors and user programs etc., are run on the ND-SATELLITE systems themselves. Data files may be kept on the SATELLITE's mass storage or on the central ND-500 or ND-100 systems.

So, the user logs on to his or her SATELLITE system, in the same manner as to any other ND system. He or she then requests, for example, the text editor or a compiler. The data to be edited or compiled and the result of the editing or compilation may be fetched from/stored on local files (on the SATELLITE's disc) or remote files (stored at the central site).

For local output, up to 1 (ND-SATELLITE/5) or 2 (ND-SATELLITE/9) printers may be connected to the SATELLITE system. The actual printers may be chosen from ND's full range of serial printers (i.e. printers which may be connected to a terminal port). Spooling will be available for these printers. This means that several users may write to the printer simultaneously and the system is responsible for queueing output and printing it when the actual printer is free.

Backup may be taken using the 1.2 Mbyte floppy disc on the SATELLITE or by copying files to the central ND system where normal backup is taken.

## ND-SATELLITE/5 System

The ND-SATELLITE/5 basic system consists of:

- CPU and memory management system
- 256 KBytes of MOS memory with error correction
- 10 MByte fixed Winchester disk
- 1.2 MByte floppy diskette
- 5 terminal ports
- Cabinet, including power-supply etc.
- SINTRAN III/VS operating System
- Spooling for 1 printer
- NOTIS-WP editor and text-formatter
- SINTRAN Utility programs
- Subsystem Package
- Resource usage Accounting System
- SINTRAN Backup System

## ND-SATELLITE/9 System

The ND-SATELLITE/9 basic system consists of:

- CPU and memory management system
- 512 KBytes of MOS memory with error correction
- 20 MByte fixed Winchester disk
- 1.2 MByte floppy diskette
- 9 terminal ports
- Cabinet, including power-supply etc.
- SINTRAN III/VS operating System
- Spooling for up to 2 printers
- NOTIS-WP editor and text-formatter
- SINTRAN Utility programs
- Subsystem Package
- Resource usage Accounting System
- SINTRAN Backup System
