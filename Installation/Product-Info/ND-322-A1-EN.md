## INTRODUCTION

The NORTEXT EDITING terminal (NET-terminal) is a terminal designed to support a variety of applications, such as:

- Newspapers
- Magazines
- Publishing houses
- Commercial printers
- Graphic centers
- News agencies

These users are all running the NORTEXT-100 Text systems. Special keys are made for covering the NORTEXT-functions. The Graphic Option module available for the NET-terminal allows the user to verify on his own screen that the job is typographically correct before typesetting. The NET-terminal is available both in a green version and a black/white version.

## FEATURES

- A full NORTEXT Text and information processing terminal
- British, Norwegian, Swedish, Danish, German, Finnish and Icelandic versions
- The position and the angle of the terminal adjustable
- The screen treated to minimize reflection and the display colour chosen to reduce eye strain
- Both a green and a black/white version available
- 15" screen with bonded anti-reflex faceplate
- A flicker-free display of up to 25 lines of 80 characters each
- Upper and lower character sets available for each language
- A special PI font with graphic characters available
- Separate keyboard with a low profile
- Prepared for full-screen editing support, f.ex. applications such as the NORTEXT-100 systems

## TERMINAL ADJUSTMENT

The position and the angle of the terminal can be freely adjusted to suit each individual user. The screen can be swivelled and tilted to avoid interference from windows or overhead lightening. In addition, the terminal can be raised and lowered.

## THE SCREEN

Both a green and a black and white version available. The screen shows a flicker-free display up to 25 lines of 80 characters. Each character is formed in a 9 x 14 point matrix, giving high resolution. Upper and lower case character sets are provided for each language. A special PI font with graphic characters is also available. Blink, underline, low intensity and inverse display are all included as standard features.

## THE KEYBOARD

The keyboard has a very low profile and can be used comfortably on a standard office desk. The cabling is concealed under a snap-on cover, so that the terminal gets a generally attractive appearance. The keyboard is separate from the display.

## GRAPHIC OPTION

The Graphic Option available will provide the user with a "soft typesetter function". The user may display a graphic picture representing a soft copy proof. Areas of use for the Graphic Option are NORTEXT-100 Text System, NORTEXT-100 AD Integrated Management System and NOTIS Business Graphics.

The Graphic option consists of a hardware module, which will be installed inside the NET-terminal. The Graphic output is initiated while the NET is in an editing mode. The text displayed will then be re-displayed in a justified mode, including the result of all typographical functions available in NORTEXT-100 and the relevant typesetter. The Graphic Option automatically chooses 8 of the typesetter fonts. The characters displayed will be approximated, but the width is correct.

The text shown in the graphic mode is a window of the complete text, starting at the first line shown on the display in the editing mode. The justified text displayed in the graphic mode can be scrolled vertically and horizontally by using the standard cursor key. To return to the normal editing mode, the user presses the HOME key.

## TECHNICAL DATA

### DISPLAY CHARACTERISTICS:

- **CRT:** 15" diagonal with bonded anti-reflex faceplate
- **Phosphorus number:** Green screen...............P31
  Black & white screen..Toshiba L3 or Philips
- **Characters per line:** 80
- **Number of lines:** 25
- **Character matrix:** 7 x 9 dot characters in a 9 x 14 dot cell
- **Character set:** Full upper and lower case character sets are available in German, French, Icelandic, English, Finnish, Swedish, Norwegian and Danish versions. All standard sets contain semigraphic characters for line drawing, histogram plotting and numeric subscript/superscript
- **Special font:** PI font
- **Display modes:** The display mode can be controlled on a character-by-character basis. 16 display modes are available: Combinations of underline, blink, inverse video and low intensity. In addition, double-width and invisible display are included
- **Refresh rate:** 70 Hz
- **Line frequency:** 30 kHz
- **Cursor:** Underline blinking and steady block cursor are softswitch selectable

## CONTROL FUNCTIONS:

### Cursor control:

- Cursor right
- Cursor left
- Cursor up
- Cursor down
- Cursor home
- Direct cursor positioning

### Scroll control:

- Scroll up
- Scroll down
- Smooth or step scroll is selectable by soft-switch

### Tab functions:

- Horizontal tab
- Backward horizontal tab
- Horizontal tab set
- Horizontal tab clear
- Clear all tabs

### Editing functions:

- Insert character
- Delete character
- Erase character

### PUSH-key loading:

16 PUSH-key strings can be loaded from the host computer. The following functions are menu driven: Convenience switches, function switches, communication switches, push-keys, tabulation rack

## KEYBOARD CHARACTERISTICS:

- **Total Number of keys:** 121
- **User definable function keys:** 30 (software controlled)
- **Interface:** Serial asynchronous communication is used between keyboard and terminal. Communication is bidirectional allowing commands to be sent to the keyboard
- **Cable:** Six-wire coiled flexible cable
- **Indicators:** Nine LEDs are used. Three are programmable and those remaining indicate the line interface status
- **Sound:** A bell and click transducer are included. Their operation is controlled by soft-switches
- **Interface:** The terminal is interfaced to an ND computer via a 20 mA current loop interface or the CCITT V.24 (EIA RS-232 C) standard connection via modems and modem interfaces. A start/stop character format with two stop bits. (11 bit code) is used. Parity bit generation and error detection use even parity. Transmission speed is switch selectable from 110 to 9600 baud
- **Printer control:** 
  - Start relay to printer
  - Stop relay to printer
  - This allows for hard copy and independent printing (terminal bypass). 
  - Transaction logging can be initiated by remote switch setting.

## GRAPHIC OPTION

**Scaling**  
Scaling can be specified by any real number (up or down).

**Small points**  
Characters below a given point size are displayed as a line. This is very useful, when only a visual appearance of the text is wanted. All text above the given point size will be displayed in characters (titles etc.).
