### Introduction

The ND 529 MagTape Drive, the ND 536 Dual Density Formatter, and the ND 556 MagTape Controller constitute a high performance magnetic tape system, using vacuum buffer columns for gentle tape handling. The tape system features ANSI and industry compatible 800 bpi NRZI/1600 bpi PE format capability.

### Features

- 9 tracks 800 bpi NRZI/1600 bpi PE, 75 ips ANSI and industry compatible
- Three inch wide vacuum column for tape buffering
- One formatter accepts 4 drives
- 250 ips rewind speed
- Easy tape loading by using self-seating reel hub and simplified tape path
- Read-after-write dual gap head and error checking logic
- Electronic write deskewing using a digital deskewing technique
- Vacuum operated tape cleaner
- Low audible noise
- Options include:
  - single density, 800 bpi NRZI
  - single density, 1600 bpi PE

# Product Description

The ND 529 high performance MagTape system is a new generation of cost-effective vacuum column tape transports. The transport is using 3" wide vacuum columns, which minimizes the audible noise level generated by the vacuum pump system. Consequently, while still maintaining industry standard tape tension, the vacuum pressure is 50% less than competitive models. The savings in vacuum pump requirements result in a much quieter unit, that also consumes far less power than others.

The vacuum pump system maintains a positive air pressure in the tape compartment area and also makes sure that the air is well filtered. This standard feature provides the tape the cleanest operating environment and together with the vacuum type tape cleaner assures the highest possible data reliability.

Annoying reel servo "hunting" is eliminated by a unique servo motor control design. Besides keeping the tape reels still, this feature eliminates unnecessary power consumption, associated with band-bang type reel servos.

The single capstan drive system carefully smooths out both acceleration and deceleration to provide the tape with kindest possible treatment. The design of the tape path assures the sensitive tape oxide contacts only the tape cleaner and the head.

Exceptional care goes into the mounting of the head and tape guides to minimize tolerance build up, thus guaranteeing tape interchangeability. A special digital write deskewing technique provides reliable reading in both forward and reverse directions.
