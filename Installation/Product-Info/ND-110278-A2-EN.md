## Page 2

# ND Matrix Printer ADP 515

## Introduction

The ND MPA 515 is ideally suited to provide hard copy output for small business and personal computer systems. The printer emulates the most widely-used professional and personal computer printers and provides many other standard features and options. These include operator-selectable print styles, tractor-feed capability and five different print modes. In addition, high-resolution, dot-addressable graphics are a standard feature, providing added capabilities for professional system requirements.

## Features

- up to five selectable print modes (*)
- up to five character styles (*)
- five character pitches
- fifteen national character sets (*)
- dot-addressable graphics
- flexible paper handling
- operator convenience
- universal power supply

|                | NLQ gothic: 9 dots H x 18 dots V     |

|                | dots horizontally; double strike     |

| Print Head     | Nine wire impact                     |
| Head Slew      | 22 in./sec (559 mm/sec)              |
| Line Feed Interval| 40 msec at 6 lpi                  |
| Character Spacing| 10, 12, and 17 cpi                 |

| Print Line     | 13.2 in. (335 mm) (132 columns @ 10 cpi)|
| Graphics Mode (*)| 6, 7 or 8-pin addressable           |
|                | H resolution: 60 to 204 dpi          |
|                | V resolution: 72 or 144 dpi          |
|                | Speed: 5760 dots/sec max             |
| Buffer Size    | 2K character                         |
| Ribbon         | Cartridge, black inked nylon,        |
|                | 4 x 10^6 character nominal life       |
|                | (draft printing)                     |
