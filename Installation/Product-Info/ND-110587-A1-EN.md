# OpenLAN

## Introduction

The ND 110587 OpenLAN Secure Local MAC Bridge (OL-SLMB) is a high-performance, protocol-transparent Ethernet-to-Ethernet bridge. It interconnects two Ethernet (IEEE 802.3) segments (Cheapernet or Thick Ethernet) using transceiver cables to create a local area network (LAN) that extends beyond Ethernet's size restriction.

A data-link level (ISO Layer 2) bridge, the OL-SLMB routes packets based on Ethernet addresses only. It continuously monitors traffic on the network, filtering and discarding messages addressed to local stations, and forwarding only inter-LAN packets. Since the OL-SLMB is protocol-independent, data can be passed between Ethernets that are running incompatible high-level protocols such as XNS, TCP/IP, DECnet, OSI, and COSMOS.

The OL-SLMB isolates excess inter-LAN traffic and protects network security through a programmable filtering feature. Custom filters can be used to discard packets based on specific Ethernet addresses. Arbitrary masks on byte, word, or double-word boundaries can be set up to filter specific packets, allowing the network manager to increase network performance and restrict inter-network access.

# OpenLAN

## Features

### Separate yet Integrated Networks
The OL-SLMB allows you to separate local area network segments, while still allowing communication between them. This can be done either for security or performance purposes. Only inter-segment traffic, with a destination on the other side of the bridge, is forwarded.

### Security Filters
The OL-SLMB can be programmed to filter communications in situations where security is of importance. Custom filters can be set up to discard packets based on source or destination addresses. Traffic can be filtered based on arbitrary masks on any packet byte, word, or double word.

### Auto-Learning
The OL-SLMB continuously and dynamically learns which stations are local and which are remote by simply listening to the traffic on the network. This greatly simplifies installation and reconfiguration of network stations.

### Integrated Network Management
An interactive, sophisticated network management system is built in. Commands are available to configure system parameters, set custom filters, specify routing information, and display performance and throughput statistics.

### Stand-alone System
The OL-SLMB is completely self-contained and requires no additional host support. Its integrated network management features can be accessed directly through a local console port.

### High-Performance Architecture
Two multiple high-speed 68000 processors allow the bridge to filter local traffic at 7,000 packets per second and forward inter-LAN traffic at up to 2,500 packets per second.

### Protocol Transparency
Operating at the data-link level, the bridge is protocol-transparent. A multi-vendor network can be set up to pass among multiple Ethernets.
