# ND GIGATAPE SYSTEM

## Introduction

The ND Gigatape System (ND GTS) is a revolution in backup technology, giving vast savings in time, money, and operator effort. ND GTS satisfies the demand for inexpensive, convenient backup of magnetic disks.

ND GTS is a high-performance, high-capacity tape system that uses 8 mm cartridge tapes and can store up to 2.2 Gbytes of data on a single cartridge. This tape system uses standard SCSI as its interface.

## Features

- Helical-scan recording method
- Standard 8 mm removable tape cartridge
- 2.2 GB capacity per tape
- 5 1/4 inch full-height size
- SCSI controller
- Advanced error detection and correction
- High MTBF
- 246 KB/sec. data-transfer rate

## Product Description

The ND Gigatape System is a removable, rewritable-medium tape system that provides a reliable and efficient backup possibility for the users. The 2.2 GB-capacity tapes and the necessary software allow copying of several disks into one tape, thus saving significant amounts of storage space. The high recording density is achieved by employing the advanced helical-scan recording technology.

ND GTS provides high reliability, since it uses advanced Error Correction Code (ECC), and the read-after-write technique.

The medium for the ND GTS is the standard, 8 mm cartridge tape, whose compact physical size and large storage capacity give significant savings in storage space compared to traditional magtapes.
