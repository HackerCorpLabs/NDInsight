# ND Statistical Multiplexer

## Introduction

The ND Statistical Multiplexer makes it possible to connect a combination of asynchronous terminals and/or printers on a local site to a central computer via a Public Data Network (PDN) line or a leased line. This makes the multiplexer suitable for a small office wanting to take advantage of a central computer resource without buying its own computer.

## Features

- Eight asynchronous channels with speeds up to 19.2 Kbps
- Link speed up to 19.2 Kbps
- Automatic speed detection range from 150 to 9600 bps
- Flexible configuration possibilities
- Front panel with LCD display and indicators
- Continuous exploitation of the link speed capacity
- Dedicated or floating supervisor port
- Menu-driven supervisor control
- Network of multiplexers possible
- Monitoring of link and channels
- Link and channels statistics

## Product description

The Statistical Multiplexer is characterised by high performance, easy installation and operation. The multiplexer may be configured in one of the following ways: local front panel control, local/remote floating supervisor port or local/remote dedicated supervisor port. The need to memorise commands, options and syntax is eliminated by a completely menu-driven configuration facility. All available options are presented on an asynchronous ASCII terminal or on the integral 32-character liquid crystal display (LCD). All parameters have a default value set at the factory, which can be restored after changes if required.

The dedicated supervisor port allows configuration, monitoring, problem diagnosis and statistics enquiries during multiplexer operation. The supervisor can sign on either to the local or the remote end of the link without interfering with operation or data flow. Performing supervisor functions this way will not affect normal data traffic. If there is a need for immediate notification of potential problems, the monitor mode reports events occurring on both channel and link interfaces for the local and remote sites.

Security features include front panel access which can be disabled from the supervisor port. Floating supervisory capacity can be enabled or disabled on a per-port basis. Furthermore, access to the supervisor function can be password-protected.

The buffer capacity of 16 Kbytes is shared on demand by the channels. Each channel is assigned a minimum of 320 bytes of the buffer space to prevent lockout. The multiplexer will handle an aggregate of 76.8 Kbps in constant full-duplex traffic (with flow control), and a 19.2 Kbps link without loss of data.

# ND Statistical Multiplexer

## Technical Specifications

### Functional

- **Number of channels**: 8
- **Channel speeds**: Up to 19.2 Kbps
- **Link speeds**: Up to 19.2 Kbps
- **Maximum aggregate input**: 768 Kbps
- **Autobaud rate detection**: 150 to 9600 bps
- **Buffer capacity**: 16 Kbyte

#### Channel Interface

- **Channel interface**: CCITT V 24
- **Link interface**: CCITT V24/X21bis
- **Link protocol**: Modified HDLC, X.25 level 2
- **Flow control**: XON/XOFF or CTS/BSY
- **Error control**: 16-bit CRC check
- **Code level**: 5, 6, 7 and 8 data bits
  - 1, 1.5 and 2 stop bits
  - 1-bit parity

#### Front Panel Indicators

- Power on
- Flow control
- Link down
- Data loss

#### Integral Display

- Liquid crystal
- 2 lines of 16 characters each

#### Channel Statistics (a selection)

- Current and peak buffer utilisation
- Parity and framing error

#### Link Statistics (a selection)

- Current and peak transmit utilisation
- Current and peak receive utilisation
- Current and peak frames received
- Current and peak frames received in error
- Current and peak frames retransmitted

#### Other Features (a selection)

- Statistics reset
- Channel loopback
- Channel reset
- Channel status
  - data activity
  - EIA signal states
  - flow control states
  - loopback states
  - force EIA signal states
- Link loopback
- Link reset
- Power-on diagnostics

### Power

- **Power options**: 75 to 240 V, 50/60 Hz
- **Power dissipation**: 20 W, 0.2 A

### Environmental

- **Operating temperature**: 7° to 35°C
- **Relative humidity**: 0 to 95%

### Physical Dimensions

- **Height**: 9.9 cm
- **Width**: 39.4 cm
- **Depth**: 34.3 cm
- **Weight**: 3.6 kg

## Prerequisites

- Any ND computer with terminal interface
- Asynchronous devices like terminals, OWS and printers
