# LINE-PRINTER MATRIX M-T  
## 300 AND 600 LPM

### Introduction

The LINE-PRINTER MATRIX M-T is a general-purpose line-printer for the medium speed range. The printer will be delivered in two models, offering 300 or 600 lines per minute. Upgrading from 300 to 600 lpm will be possible.

The printer is connected to the ND systems with a standard serial interface, and can be used with all ND-100 and ND-500 systems.

### Features

- Simple and reliable design
- Quiet operation
- Several national character sets
- Hardware-adjustable vertical and horizontal pitch
- Several fonts can be set in hardware

### Product description

This printer will work in normal line-printer mode. The speed is 300/600 lines per minute. Using uppercase and lowercase, the corresponding print speed will be approximately 240/480 lpm.

Other fonts, OCR-B and Correspondence, are available. These must be switched on the printer. When using these fonts, the printing speed is lower. Depending on paper weight, up to 5 copies can be used. The printer is connected by a standard serial interface, and the distance from the computer can be extended by the use of limited distance modems.

The printer has comprehensive selftest and diagnostic features.
