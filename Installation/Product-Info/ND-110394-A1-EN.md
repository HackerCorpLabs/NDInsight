# OpenLAN OWS Adaptors

## Introduction

To integrate Office Workstations (OWS) into a network requires an interface or an adaptor. Ethernet has become one of the very few de facto standards for networked solutions and the cabling appears in two versions, Ethernet and Cheapernet. Norsk Data delivers adaptors for both types: the ND 110394 for Cheapernet and ND 110386 for Ethernet (thick cable). The adaptors connect the workstations to the network. The Cheapernet adaptor has a built-in transceiver, while the Ethernet adaptor requires a transceiver. Ethernet is based on the TCP/IP protocol.

The OWS OpenLAN adaptors are multi-function, board-level communications servers that combine the benefits of personal computers with the power and flexibility of a corporate local area network.

## Product Description

### Hardware

The OWS OpenLAN adaptors are high-performance, intelligent LAN adaptors offloading the communications processing from the OWS. An on-board Motorola 68000 microprocessor is coupled with the Intel 82586 co-processor to achieve efficient network performance. Full 512K RAM and up to 128K ROM memory store software and provide communications buffers. By using an advanced shared-memory interface between the OWS and the adaptor board, the communication runs concurrently with OWS applications, thus increasing OWS performance. The OWS OpenLAN adaptor board is a full-size PC board occupying one 8-bit position in the OWS crate.

The Cheapernet adaptor is delivered with TCP/IP software, built-in transceiver and Cheapernet T-connector.

The Ethernet adaptor is delivered with TCP/IP software and 15 m transceiver cable for OWS. The transceiver unit is not included.

### Software

The OWS OpenLAN adaptors are designed for use with Ethernet (IEEE 802.3) and TCP/IP protocols including Telnet and FTP.

The OWS can communicate directly with computers and workstations from other vendors supporting TCP/IP protocols.

When you use FTP, you can send and receive files directly to and from any remote TCP/IP host. In addition, FTP includes commands like list, rename, and delete remote files. The Telnet module provides direct remote log-in to non-ND TCP/IP hosts connected to the same OpenLAN.

## Specifications

System architecture: MC68000, 8MHz - 512 K RAM - 128 K ROM - Intel 82586 LAN co-processor.  
Network Interface Options: Baseband 10 Mbps IEEE 802.3 compatible Ethernet interface, Ethernet or Cheapernet cable.  
Protocol: TCP/IP with Telnet and FTP.  
Physical dimensions:
- Length - 13.3 inches/33.8 cm
- Height - 4.2 inches/10.7 cm

- MS-DOS® version 3.1 for OWS-12
- MS-DOS® version 3.2 for OWS-55
- MS-Windows® 2.0
