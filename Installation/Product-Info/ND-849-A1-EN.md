# ND 849 Terminal Cross Coupler

## Product Description

The ND 849 Terminal Cross Coupler is a signal distribution box to be used as a switchboard for remote terminals.

The ND 849 is equipped with 24 female socket connections. Two twisted pairs of cable for each terminal are necessary for remote connection. For ND standard cables, the distance between the CPU and the ND 849 is 7 meters, otherwise, there are no practical limits. On sites where there are terminal connections, sockets of type ADO 8 AP kode B2 should be used.

By using the ND 849 any terminal interface may be linked up with any terminal connector.
