# ND 433X LINE PRINTER, 1000 lpm

## INTRODUCTION

- The ND 433X Line Printer is a horizontal moving font line printer which utilizes time-proven design principles to ensure long, trouble-free operation. The carrier employs 8-character links riding on a mono-rail track to ensure precise vertical print alignment, and the interchangeable links enable character sets to be replaced easily. In addition to time-saving full time buffering, the ND 433X printer is versatile enough to accept 6-part forms from 3.5" to 19.5" wide.

# Features

- 8080A microprocessor controller (specific customer requirement software programmable)
- Print data buffer: Single line memory
- Self Test exercises printer off-line
- Print Inhibit Switch inhibits print hammer firing off-line
- Alarm Panel indicates printer, paper supply, paper jam status
- Diagnostic Panel facilitates maintenance
- Motorized tractors control horizontal positioning and tensioning, manual infinite forms position (vertical) control.
- Paper receptacle
- Vertical forms control:
  - VFU 8-channel; Standard 1" (25.4 mm) paper tape
- Linefeed 0 to 63 lines
- Autolinefeed Automatically single or double line spaces the printer, skips over the perforation
- Paper Motion Detector indicates paper jam and stops printer
- Ribbon Control: Automatic reversing; continuous tracking
- Enclosure: Sound deadening cabinet
- Locking casters
- 12-channel VFU with operator selectable 6/8 lpi switch
- Static eliminator
- Adjustable paper catcher
- Elapsed time meter
- Short-time adapter
