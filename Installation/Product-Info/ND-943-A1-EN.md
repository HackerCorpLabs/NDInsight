## INTRODUCTION

A typesetter adapter is hardware between a ND100 interface and a typesetter. The adapter converts the signals from ND100 to suitable signals for the typesetter.

Usually this means a conversion from serial link to parallel link.

## PRODUCT DESCRIPTION

The typesetter adapter (Misil-8) is a universal box used for conversion of electronical signals.

The adapter is used for every typesetter needing input signals in a parallel form. This means that it is possible to use a standard serial interface in the ND-computer.

Switching between different typesetters is done with straps and switches.
