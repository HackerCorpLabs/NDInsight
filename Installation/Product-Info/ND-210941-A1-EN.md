## INTRODUCTION

NORTEXT-100 PRINTMAN is a flexible and reliable system for price calculation, follow-up of offers and orders and invoicing in small and medium-sized printing plants.

NORTEXT-100 PRINTMAN utilizes the same NET-terminals as NORTEXT-100 Text systems. PRINTMAN looks after the company's offer and order routines, provides cost management and gives information on profit or loss at the different stages in the production.

NORTEXT-100 PRINTMAN is also a sales tool, providing potential customers with detailed price offers without delay.

NOTIS-RG (Report Generator) — is included in NORTEXT-100 PRINTMAN and defines a range of reports useful for future planning.

NORTEXT-100 PRINTMAN is a part of the integrated NORTEXT concept, but can be operated as a stand-alone system.

## PRODUCT DESCRIPTION

NORTEXT-100 PRINTMAN can be operated on ND-110/CX or ND-500/CX systems operating under the SINTRAN operating system. The database systems to be used are either ISAM or SIBAS. For customers already using SIBAS, the SIBAS version is a natural choice. The ISAM version is an alternative for new customers.

These are the different modules within the NORTEXT-100 PRINTMAN:

- Basic files
- Pre-calculation/price estimation
- Order processing
- Post-calculation/cost of sales
- Report generation

## BASIC FILES

Basic files are the main files where all central basic information are stored. The most important parameters are:

- Lists of customers
- List of suppliers
- Material register with storing functions
- Reports on storage
- Price lists
- Departments/cost centers

## PRE-CALCULATION

The pre-calculation module is needed for providing potential customers with detailed price offers.

The pre-calculation contains the following functions:

- Calculation
- Price quotation
- Re-calculation of previous orders
- Order-making

## ORDER-PROCESSING

When registering an order one can register new customers directly or make a seek in the register of customers by means of name or the customer number.

The order-processing module has the following functions:

- Registration of orders
- Order confirmation
- Materials needed

## POST-CALCULATION

The consumption of time and material is recorded and will be charged on the separate orders. Work done by sub contractors can also be registered in the same screen picture.

Price and material information can be retrieved automatically from the Basic files. However this price and material information can be overruled and exchanged by the operator if needed.

The registers in the Basic Files module contain information which makes it possible to create reports telling about costs on machines or departments.

These are the functions covered by the Post Calculation module:

- Time and material registration
- Basic information for invoicing
- Transferal of data to an accounting system

## REPORT GENERATION

NORTEXT-100 PRINTMAN produces the reports needed for statistics and planning for the future. For this purpose NOTIS-RG (Report Generator) is implemented as a report generating module.

Examples of such reports are:

- Invoice
- Pre- and post-calculation
- Dispatch note
- Customer data
- Material overview
- Turnover pr. customer
- Order confirmations
- Order surveys
- Price lists
- Value of orders in process

The NOTIS-RG makes it possible to generate further reports if needed.

### "HELP" FUNCTIONS

A "HELP" key is available on the keyboard. By pressing the "HELP" key, the user will immediately get the user manual on the screen, which will give the necessary description of commands and parameters to perform a given task.
