# ND 567 DMA Controller

## Introduction

The ND 567 – DMA CONTROLLER – is designed to take care of all address decoding, Requests, Interrupts and acting as an interface between the standard I/O Bus and a local data bus. The module is used for all Norsk Data DMA devices as disks and MagTapes.

The module occupies only one standard I/O slot and is always used together with either the DMA Receiver 1014 or the Buffered DMA Receiver 1092 modules.

## Features

- IOX Address Decoding
- DMA Request and Grant Control Logic
- DMA and Error Interrupt Control
- Control of Memory Address Register
- Used by all standard Norsk Data DMA equipment

## Product Description

The ND 567 may be put into any standard I/O position and is the only module of a DMA interface/controller which is on the I/O Bus.

The remaining part of a DMA interface/controller is normally at the end of the I/O crate.

The main functions of the ND 567 are to take care of the communication with the I/O Bus and to handle most of the control functions associated with a DMA device.
