# ND-5100/xi

## Introduction

The ND-5100/xi is a departmental computer system for up to 16 users, based on the 32-bit 80386 processor. The system runs the UNIX® operating system. It is well suited as a multiuser system or as a server in a distributed environment.

## Features

- Well suited as entry-level systems or as elements in a distributed configuration
- Offers fast interactive access for text and information processing, together with the power for online database processing
- 32-bit 80386 CPU chip operating at 16 MHz. An optional 80387 numeric co-processor can be installed for accelerating mathematical calculation speed
- Up to 18 MB physical memory
- Up to 16 directly connected terminals
- Internal disk capacity up to 350 MB
- Internal 155 MB streamer tape drive for fast systems backup
- Internal 1.2 MB 5 1/4" floppy drive
- Optional Ethernet controller
- Optional X.25 controller
- Runs SCO XENIX System V (UNIX System V.3-compatible)
- MS-DOS® applications can be run from UNIX
- Integration between MS-DOS and UNIX file system
- Gives access to professional UNIX applications as well as the many MS-DOS applications
- Serial/parallel adaptor
- Full upgrading between the different models

## Product Description

The ND-5100/xi comes in several different models dependent on the number of users and disk capacity. All models have one 1.2 MB floppy, one 40 MB hard disk and one EGA colour monitor. The system bus is PC/AT-compatible and permits a wide variety of industry-standard boards to be installed. The serial/parallel adaptor board can connect up to three devices (e.g. printers).

## Expansion Possibilities

Standard PC/AT-bus compatible cards can be installed in the free slot positions, for example Ethernet or X.25 controller boards. There is space for two disks inside the cabinet. It is possible to upgrade between all the models, except from C to D/E models.

## Systems Architecture

The ND-5100/xi is a part of Norsk Data’s Systems Architecture For Expansion (ND-SAFE), which allows you to increase system performance easily as your needs grow. In addition to the upgrading possibilities within the ND-5100/xi models, the high-end ND-5000/xi Compact and Large System furnishes the potential for further increasing your computer power.

- MS-DOS programs can be executed under UNIX
- Electronic mail and networking with uucp
- TCP/IP communication

- Remote login with telnet
- Network File System NFS®
- Text processing
- Editors
