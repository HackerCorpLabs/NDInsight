# ND-NOTIS TERMINALS

## Product Description

Norsk Data delivers interactive systems for Office Support, ADP and Technical-Scientific use. In order to give the best possible support to its users, Norsk Data offers the best terminals available on the market with regard to functionality and ergonomy.

The ND-NOTIS asynchronous terminals may be used with any of Norsk Data's interactive systems, but are especially well integrated with ND-NOTIS, Norsk Data's Office Support system. A large number of special function keys on the keyboard support NOTIS-WP and other ND-NOTIS products such as NOTIS-IR, NOTIS-ID, and others.

The ND-NOTIS terminal comes in two basic versions, one with green and the other with white screen, thus giving the user the opportunity to choose the appropriate terminal for the intended use. A number of options are available for both versions. By including one of the Graphic Options, the terminal may be used with the ND-NOTIS graphic presentation tools, NOTIS-BG and ND-NOTIS-DRAW.

The ergonomically designed ND-NOTIS terminal and keyboard enhance a comfortable and pleasant working environment. The terminal can be tilted, swiveled, raised or lowered to suit the individual operator. The picture is totally flicker-free and stable, with a refresh rate of 70 Hz. The surface of the screen has been specially treated to diminish reflections. The terminal is totally silent; the design has eliminated the need for a cooling fan. The cabling is concealed under a snap-on cover, giving the terminal an overall smooth look.

The separate keyboard has a very low profile, permitting the terminal to be placed comfortably on an office desk. The function keys have been carefully designed and clearly marked with different colours for ease of operation. Push-keys for as many as 16 user-programmable character strings have been provided. The user can store recurrent key sequences, and recall them whenever needed by the push of a single key.

The ND-NOTIS terminal is available in several language versions.

## Features

- 15" screen with bonded anti-reflection faceplate.
- The stand has adjustments for height, tilt and swivel.
- Low-profile keyboard with clearly marked and coloured functions keys.
- Function keys for Mark, Delete, Copy, Move, Function, Print, Help, Cancel, Underline, Justification and other functions.
- Numeric keypad.
- Large choice of character sets, including Greek, mathematic and semi-graphic characters.
- Full Teletex character set.
- Local tabulator handling.
- Local and remote printer control, giving screen dump, terminal bypass (output to printer only) or transaction logging.
- PUSH-keys to record and recall recurrent character strings.
- Softswitch setup, allowing all terminal-relevant functions to be set on internal menus.
- Seven of the keys in the upper right section of the keyboard may be used in combination with the CTRL key to send local commands to the terminal. Such commands are: Starting or stopping local printout, clearing error conditions and setting mode switches and "break".

## Available Options for ND 103200 and ND 110001

### ND 103211 Graphic Option

With the Graphic Option, the ND 103200 and ND 110001 are turned into a Tektronix 4010/4014 compatible graphic terminal, with extensions for enhanced text manipulation. The resolution is 720 x 336 dots. The Graphic Option makes it possible to view and manipulate graphs on the screen, and lets the user make full use of such tools as NOTIS-BG and NOTIS-DRAW.

These tools offer easy-to-use graphic presentation techniques on a minicomputer, helping you to present your figures and statistics in a more understandable way. The Graphic Option is also available as a Field Upgrade Kit, ND 103210.

### ND 110072 Tracer Graphics Option

With the Tracer Graphics Option, the ND 103200 and ND 110001 are turned into a Tektronix 4010/4014 compatible graphic terminal, with extensions for enhanced text manipulation. The resolution is 720 x 336 dots. The Tracer Graphics Option makes it possible to view and manipulate graphs on the screen, and lets the user make full use of such tools as NOTIS-DRAW and NOTIS-BG. A Mouse Option, ND 110073, may be attached via the V24 connector, making it even easier to draw and manipulate graphic elements with NOTIS-DRAW.

The Tracer Graphics Option excludes split speed communication from the terminal.

These tools offer easy-to-use graphic presentation techniques on a minicomputer, helping you to present your figures and statistics in a more understandable way. The Tracer Graphics Option is also available as a Field Upgrade Kit, ND 110075.

### ND 110073 Mouse Option

The Mouse Option offers a new level of user-friendliness which makes it even easier to produce graphic elements and illustrations with ND-NOTIS graphic presentation tools such as NOTIS-DRAW. The Mouse Option consists of a Mouse device and an adapter for the Tracer Graphics Option. The Tracer Graphics Option, ND 110072 is a prerequisite.

The Mouse device occupies the space reserved for the V24 interface. If a local printer is desired, it may be connected with the V11 connector. A suitable printer is the ND 110080 PT88S InkJet. 

The Mouse Option is also available as a Field Upgrade Kit, ND 110076.

### ND 110074 VT-100 Emulator Option

The VT-100 Emulator Option makes it possible to use the terminal in both ND-NOTIS and VT-100 mode. The option is softswitch selectable. The VT-100 Emulator is also available as a Field Upgrade Kit, ND 110077.

### ND 103231 Print Buffer Option

The Print Buffer Option makes it possible to print on a locally attached printer in background mode, so that the terminal is free to perform other tasks. The Print Buffer Option is also available as a Field Upgrade Kit, ND 103230.

### ND 102431 Printer Interface Option

The Printer Interface Option makes it possible to attach a local printer to the V24 port. The Printer Interface is also available as a Field Upgrade Kit, ND 102430.
