# OPTICAL DISK DRIVE

## Introduction

The LD 1200 is a 12" optical-disk drive with a double-sided removable disk which can store 1 GB on each side of the disk. The information on the disk can only be written once and cannot be erased. The ND optical disk drive is suitable for applications like information archiving, where permanent information written on the magnetic disk is copied to the optical disk and stored permanently.

The software implementation of the optical-disk drive allows copying of a whole directory on a magnetic disk onto an optical disk. Although copying single files to the optical disk is not possible, the user can access and read single files from the optical disk.

## Features

- Removable disk.
- Large storage capacity. ND's optical disk is double-sided and can store 1 Gigabyte of data on each side.
- Long lifespan / high availability.
- Non-erasable media.
- Built-in power supply and cooling system.
- 1.33 MB/Sec. burst transfer rate.
- Reed-Solomon Error Correction Code (ECC).
- Direct Read During Write (DRDW).
- Preformatted spiral-grooved media.
- 19" rack-mountable, 5 1/4" high; fits in standard Filestore cabinet.
- Maintenance panel for fault diagnostics.

## Product description

The LD 1200 optical-disk drive is based on the WORM (Write Once Read Many times) technology. With this scheme the information is written onto the disk once and permanent storage is provided for.

In the optical-disk drive, the reading and writing operation is done by a semiconductor laser which is integrated into the drive. The laser beam creates holes on the sensitive disk surface during the write operation. The hole/no hole system translates into the one/zero format. During the read operation, the hole/no hole case is detected by the intensity of the light that is reflected from the laser beam, which is then translated into the zero/one format.

The Error Correction Code (ECC) in the LD 1200 optical-disk drive is based on the Reed-Solomon method. The user data is written with the ECC check symbols onto the disk. These check symbols are later used to detect and correct errors during the read operation.

The LD 1200 optical disk consists of two 12" diameter glass disks that are bonded to each other and separated by an inner and an outer spacer ring. The disk is coated by a sensitive layer containing spiral grooves that include the tracking and other information. Each side of the disk contains 32000 tracks. A track is divided into 32 sectors, each containing 1024 user bytes.
