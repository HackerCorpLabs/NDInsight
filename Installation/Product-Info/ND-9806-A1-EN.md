# ND WORKGROUP SERVER

## Introduction

ND Workgroup Server is a server for a group of ND Office Workstations (PC/AT-compatible) connected together in a Local Area Network (OpenLAN). This server provides the following services: file sharing, printer sharing, electronic mail, database access from workstations to ND host and communication gateway to a remote or local ND host system.

The ND Workgroup Server is the ideal solution for large organizations with local or remote branch offices using workstations on a LAN. This server is suited to provide local resources and services for the networked workstations in the branch offices, and access to central ND host resources in the head office.

The ND Workgroup Server is available in three basic models that support X.25, X.21/leased line or Ethernet connections to the ND host.

## Features

- Offers resource sharing for workstations.
- Off-loads the ND host machine by processing the server functions locally.
- Provides better performance for workstations, since some resources are available at local sites rather than in the remote host.
- Provides the users with extra functions not available on the workstation.
- It is easy to operate, use and install.
- ND-120/CX CPU with 4 MB on-board memory provides the power for processing the local server functions.
- 125 MB disk capacity for shared file storage.
- Streaming tape drive with 125 MB capacity for backup.
- Interface for four directly connected printers.
- Ethernet controller for LAN connection.
- Up to 16 ND workstations per Workgroup Server.
- Several Workgroup Servers in a LAN or Wide Area Network (WAN).
- Communication software for connection to ND host and the workstations.
- NOTIS-DS, provides facility for file sharing.
- NOTIS-ID, provides electronic mail facility for the whole organization.
- ND-SPRINT, provides facility for sharing printers.

## Product Description

The Workgroup Server is an ND system configuration, capable of serving a group of ND Office Workstations (up to 16) connected to a LAN and providing them with the following services:

- Electronic mail
- Document Storage
- Printer(s) with spooling
- Database access from workstations to ND host
- Communications to ND host (local or remote)

## System Configurations

The ND Workgroup Server configuration consists of an ND-120/CX CPU with 4 MB memory, housed in a Satellite cabinet which easily fits under a desk in an office environment. The system includes a 125 MB fixed disk drive, a streaming tape drive for backup, 4 printer interfaces, workstation communication hardware and software, SINTRAN with utilities, and the server software.

The Workgroup Server consists of three basic models which provide for X.25, X.21/leased line or Ethernet connections. The standard configuration for all models includes:

### Hardware:

- ND Satellite Cabinet
- ND-120/CX CPU with 4 MB memory
- 125 MB disk drive
- Streaming tape drive with 125 MB tape capacity
- 1.2 MB Floppy disk drive
- Disk / Streamer / Floppy interface
- Printer interface, 4 lines
- Ethernet II controller, for LAN connection
- Transceiver cable (15 meter) for LAN connection

### Software:

The Workgroup Server software package consists of the following:

- SINTRAN III Operating System
- SINTRAN III Backup System
- SINTRAN III Utility Programs
- Menu-controlled operation files
- User Environment, menu system
- Telefix, remote maintenance system
- NOTIS-ID, electronic mail system
- NOTIS-DS, document storage system
- ND-SPRINT, spooling system
- COSMOS Basic module, communication system
- OpenLAN server/Ethernet, for communication with workstations
- Disk Restore, for restoring system disk after failure
- Test programs

### In addition, each model includes:

#### Model W1 for X.25 connection (ND 9806):

- X.25 PIOC interface
- COSMOS X.25 option

#### Model W2 for X.21 or leased line (ND 9807):

- HDLC interface
- COSMOS X.21 option

#### Model W3 for Ethernet connection (ND 9808):

- Ethernet II controller
- COSMOS Ethernet option

## Upgrading

The Workgroup Server is a prepackaged system and it is not possible to upgrade the hardware and/or software.

## Prerequisites

- Console (this is not delivered with the standard configuration and must be ordered if needed).
- An ND host system.
- ND Office Workstations (PC/AT-compatible).
- Ethernet Transceiver (ND 107740) or Cheapernet Transceiver (ND 110414), depending on the choice of Ethernet or Cheapernet for workstation connection. Ethernet and Cheapernet can be mixed in a LAN.

To connect the ND Workgroup Server to ND host, the following are needed on the host machine:

### For X.25 line (model W1):

- X.25 PIOC card (ND 108670)
- Cosmos X.25 option (ND 210570)

### For X.21 or leased line (model W2):

- HDLC interface (ND 107300)
- Cosmos X.21 option (ND 210403)

### For Ethernet connection (model W3):

- Ethernet II controller (ND 110063)
- Cosmos Ethernet option (ND 210580)
- Ethernet accessories

To connect the Workgroup Server to workstations, the following are needed in the LAN:

- **If Cheapernet is used for connecting the workstations:**
  - Cheapernet Coax cable between each workstation.
  - Other Cheapernet accessories

- **If Ethernet is used for connecting the workstations:**
  - Ethernet Coax cable
  - Other Ethernet accessories
