# ND 572/579 – 150 Mbyte Disk Drive

## INTRODUCTION

The ND 572/579 – 150 Mbyte Disk Drive is a random-access storage device. It uses fixed, sealed modules as the storage medium.

The ND 572/579 is designed for applications which demand high reliability and low maintenance. A sealed module protects the entire recording environment from external contaminants. The fixed media concept significantly improves device reliability and eliminates the need for costly head alignments. In addition, drive unit circuitry is easily accessible for fast troubleshooting.

## FEATURES

- No scheduled maintenance required
- Fixed, sealed media
- Write protect
- Power sequencing (local and remote)
- Power supply
- Flat input/output cable
- Variable or fixed sectoring
- Phase-locked oscillator (PLO)/data separator
- PRZ to MFM data encoder with write compensation
- Prewired for dual channel field kit

# PRODUCT DESCRIPTION

The Mini-Module Drive is a 3600 rpm, 9.677 MHz data rate, random-access, fixed-media device consisting of a drive motor and brake, power supply, logic package, and disk module, all contained within a metal enclosure. The logic package contains electronic printed circuit boards with read/write, fault, transmitter/receiver and microprocessor controlled servo electronics. The disk module contains the disk, heads actuator, and air filters and is sealed to minimize the effects of environmental contamination. Several features to enhance system integrity are included. They are phase-locked data separation, NRZ-to-MFM data conversion and daisy-chain interface capability.
