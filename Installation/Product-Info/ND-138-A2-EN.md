# ND 138/892 MOS MEMORY POWER

## INTRODUCTION

The MOS Memory Power unit is designed to be an integral part of a ND cabinet and will deliver all necessary power and voltages to the Norsk Data produced equipment which may typically be mounted inside such a cabinet. The power unit also has a battery back-up capability as standard.

The power unit exists in two versions where the only difference is the input line voltage and frequency that the unit will accept, i.e. 220V/50 Hz, 115V/60 Hz.

## FEATURES

- **Input voltage:**
  - 220V, 50 Hz (ND 138)
  - 115V, 60 Hz (ND 892)
- Overvoltage protection
- Output voltages for all processors, memory and Input/Output
- Output current limitation
- Meets the IEC 68 and the IEC 485 class 1 requirements

## PRODUCT DESCRIPTION

The unit is controlled and diagnosed by means of a front panel which contains the following:

- Power switch and Input Line Connector
- Input Fuse
- Status lamps and Margin controls
- Voltage adjustable potentiometers
- Power-on time meter

There is a remote power-on control feature that can be used when several cabinets and power units are used in one system. The unit has overvoltage and current limiting protection circuits such that no special operational precautions are necessary. However, environmental specifications must be followed.

# SPECIFICATIONS

## Electrical Characteristics

**Mains Input**  
220V +/- 10%, 50 Hz +/- 1%  
115V +/- 10%, 47-65 Hz  

**Load**  
Max. 7A/220V  
Max. 13A/115V  

**Instantaneous power-on surge**  
Max. 100A in 10 ms  

## AC Output

115V/230V for fans and auxiliary. Maximum 3.5A.

## DC Output

- +5V, either 100A or 150A for logic
- +5V, 8A, stand-by for memory
- +12V, 70mA, stand-by for memory
- +12V, 2A, stand-by for memory
- +24V, 5A for I/O interfaces and Floppy Disk
- -5V, 500 mA for Floppy Disk

## Environmental

**Temperature**  
Storage: -40 to +70°C  
Operating: 0 to +50°C with forced air cooling  

Meets the IEC 68 (Test procedures) and the IEC 485 (Safety of data processing equipment) class 1 requirements.  

**MTBF**  
35,000 hours  

**MTTR**  
1 hour  

## Mechanical

**Mounting**  
19” rack mountable on special brackets
