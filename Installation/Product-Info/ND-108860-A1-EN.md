# ND SNA GATEWAYS

## Introduction

The ND SNA Controllers, single line or multiline, allow an ND-100 with locally attached devices to connect to an IBM SNA network.

## ND 108660 SNA Gateway Controller Single Line

The Single Line controller runs one communication line. The product emulates the SNA PU type 2 secondary, and consists of the following hardware and software:

- ND 108670 PIOC with 512 Kbyte.
- ND 210569 PIOC Basic Software.
- ND 210471 SNA Gateway Single Line.

## Features

- Supports 4 different LU types (0,1,2,3)
- Supports 65 LUs
- Supports IBM maintenance requests issued by NCCF, NPDA etc.
- Logging facility
- Configuration facility
- Supports COSMOS

## Product Description

The ND SNA Gateway Module includes the ND SNA Software which covers the data-link control, the path control, the transmission control and the data-flow control of the SNA architecture. As can be seen from figure 1, the SNA Basic Software is implemented in the PIOC (ND Programmable Input/Output Controller). This relieves the ND-100 of much of the communication protocol handling. The PIOC is built around a Motorola 68000 processor with 512 Kbyte RAM. The communication lines on the PIOC use RS232 C (V.24) interface.

The application in the ND-100 may be a background program (SNA 3274 emulation or a customer-written application), or a real-time program (Remote Job Entry). Application programs may be distributed on different ND computers using the COSMOS network, giving all users access to all applications from any computer in the network.

## Network Management

The SNA Gateway Supervisor that is part of the Gateway Module, is a menu-oriented application. The program performs such functions as starting and stopping the links, monitoring and configuration. Among the monitor functions are:

- Defining a configuration,
- Indicating configuration status,
- Getting the LU status,
- Checking the performance of the Gateway,
- Indicating the quality of the line and
- Getting DLC statistics.

The configurator functions are:

- Allocating applications to dedicated LUs.
- Giving passwords to each LU.

## ND 108640 SNA Controller Multiline

### Introduction

The Multiline controller, ND 108640, runs two communication lines simultaneously. Up to 33 LUs per line may be simulated, otherwise the functionality is the same as for the Single Line Controller. The product consist of:

- ND 108670 PIOC with 512 Kbyte.
- ND 210569 PIOC Basic Software.
- ND 210616 SNA Gateway Multiline.

### Features

- Increased capacity and reliability with two lines to one mainframe.
- Access to two different mainframes.
- 33 LUs available per line.
- The mainframe/link is selectable from the application.

### Requirements

- ND-100 Computer
- SINTRAN III VSE/VSX K version
- XMSG K version
