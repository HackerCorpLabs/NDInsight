# 1/4" Cartridge Streaming Tape Drive

## INTRODUCTION

The ND 106270 is an 5 1/4" form factor, high-quality, cost-effective, cartridge streaming tape drive. Streaming is the technique of writing to and reading from a magnetic tape without making frequent stops. High capacity, compact size, and the ability to record data on industry standard 1/4" cartridge media are basic attributes of the ND 106270. Large scale integration (LSI) employed extensively in the ND 106270 electronics is designed to produce superior reliability.

## FEATURES

- High-capacity/low-cost media.
- High data-transfer rate.
- Multifunction capability.
- Intelligent control.
- Standard interface (CIQ-02).
- Data integrity.

# 1/4" Cartridge Streaming Tape Drive

## PRODUCT DESCRIPTION

- The ND 16072 Cartridge Streaming Tape Drives uses an ANSI Standard X3.55-1977 1/4" tape cartridge which is 600' or 450' long. 
- The Read/Write head assembly consists of two Read and Write heads with an Erase bar for full tape erase prior to recording. This allows the tape unit to perform a read-after-write check during a Write operation.
- A 4 to 5 run-length limited code is used because every four bits of data are translated to a corresponding five-bit code. Using this code will prevent the recording of three consecutive zeros in the data stream, thus allowing for efficient NRZI recording onto the tape.
- The 4 to 5 code also permits unique bit patterns for GAP, SYNC, and FILEMARK, which will never appear in the users' data field.
