## Page 2

# Free-standing 1600/6250 bpi, 125 ips Magtape Drive

## Introduction

The ND 110580 magtape drive is another addition to Norsk Data's magtape range. This dual-density, high-capacity magtape drive provides fast and reliable backup for disk drives. The ND 110580 magtape uses the standard 0.5 inch magtape reels, making it ideal for data exchange as well as backup. This magtape is horizontally mounted and is delivered in a compact housing.

## Features

- Dual density 1600/6250 bpi
- 125 ips streaming speed
- 0.5 inch reel-to-reel magtape drive
- Front loading, convenient for operator
- Autoload
- Electronic cache buffer
- High MTBF
- SCSI interface
- Compact, 19-inch form factor

## Product Description

The ND 110580 magtape is an autoloading, 0.5 inch reel-to-reel drive. This magtape is horizontally mounted and is delivered in a free-standing compact cabinet with a physical size of 22 x 67 x 48 cm.

The ergonomically designed front panel and autoloading features allow for convenient operation of the system. The drive automatically centers any standard tape, locks the reel, and then threads the tape.

The ND 110580 magtape drive operates in two densities using both GCR and PE recording formats, which yield 6250 and 1600 bpi densities, respectively.
