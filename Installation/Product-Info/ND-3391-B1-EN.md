# ND-110 COMPACT SERIES

## INTRODUCTION

The ND-110 and ND-110/CX COMPACT is a medium-range 16-bit computer, available in 4 models (model 11 through model 14). As a multiuser system it offers a good price/performance ratio, at a competitive total price per workstation. As it is an integrated part of the ND-SAFE concept, the ND-110 COMPACT can run all the software developed for ND's 16-bit line.

## FEATURES

The ND-110 COMPACT has the following features:
- Well suited as entry level systems or as elements in a distributed configuration
- Offers fast, interactive access for text and information processing, together with the power for on-line database processing
- Capable of off-loading a larger central system by running local tasks like text processing
- A 16-bit microprogrammed processor
- 8 free positions (7 in Model 14) for additional memory and I/O interfaces, leading to an expansion possibility of up to 48 terminals and 16 MB of memory.
- Maximum of two 24 MB internal disks and up to 1800 MB external disk capacity
- SINTRAN III operating system
- BCD (Binary Coded Decimal) Arithmetic
- 8 KB Cache Memory system that significantly reduces average memory access time

## PRODUCT DESCRIPTION

The ND-110 COMPACT Series comprises four models with internal disk storage ranging from 28 MB in Model 11 to two 74 MB disks in Model 13, and an SMD controller for external disks in Model 14. Operator communication with the ND-110 COMPACT is facilitated by the control panel indicators. The panel comprises status indicators, a security lock, and CPU and Cache Memory utilization indicators. There is a built-in Telefix adaptor, plus a printer outlet for hardcopy output from Telefix communication. The ND-110 COMPACT has a comprehensive instruction set, including bit, byte, word, double word, triple word, subroutine call and BCD (binary coded decimal) instructions.

Integer arithmetic operations include single precision memory to register operations. The 48-bit Floating Point Instructions use a 32-bit mantissa and a 16-bit exponent; the optional 32-bit Floating Point Instructions use a 23-bit mantissa and a 9-bit exponent.

A 16 level priority interrupt system comprises a complete set of all the central registers assigned to each level, thereby reducing context switching to the selection of the working set of central registers. The time required for this operation is 3.4 μs.

The ND-110 COMPACT has a maximum of 16 MB of main memory. 22 bits represent each 16-bit data word. A single bit error occurring in a word will be corrected and the error recorded; all double-bit errors and most multi-bit errors are reported to the Internal Interrupt System that interrupts the CPU.

## Memory Management System

This includes the Paging System and the Memory Protection System. The Paging System maps a 16-bit virtual address into a 24-bit physical address, extending the latter from 128 KB to 32 MB. 16 page-index tables of 64 words each (located in high-speed registers) reduce paging overhead to almost zero. The page size is 2048 bytes.

## SINTRAN III Operating System

This interactive, terminal-oriented system allows many programs written in different languages to be executed simultaneously; while real-time tasks, local and remote batch jobs, and other forms of data communication may run concurrently with timesharing users.

## The Input/Output System

The I/O system uses a bus to provide communication between programmed I/O devices, DMA controllers, memory modules and the CPU. The bus, which is controlled by the Bus Controller Drive, supports a physical address space of 32 MB for DMA devices.

## The ND-110 and ND-110/CX CPUs

The design of the new ND-110 and ND-110/CX are based on a new technology, called gate array technology. Both the CPU and the memory management system are packed into one card which results in one extra free position for memory expansion.

The ND 110/CX CPU has approximately twice the performance of the ND-110 CPU. Both CPU's are totally compatible with the ND-100 CPU.

## EXPANSION/UPGRADING

All the four models can be upgraded and expanded from their basic configurations.

The Expansion/Upgrading procedure is as follows:
- **Model 11** can be upgraded to **Model 12** by increasing the disk drive capacity from 28 MB to 74 MB, and adding a streaming tape drive.
- **Model 11 and Model 12** can also be upgraded to **Model 13** by increasing disk drive capacity to two 74 MB disks and adding a streaming tape drive.
- **Model 13** can be upgraded to **Model 14** by supplementing it with an SMD controller for external disks, thus allowing for the addition of four extra disks.

### Memory Capacity Upgrade

Memory boards can be added in steps of 1/2 MB, 1 MB and 2 MB, limited only by space in the 12 position rack.

### I/O Capacity Upgrade

Interfaces for terminals, printers, magnetic tapes and other peripherals may be added, limited only by space in the 12 position rack.
