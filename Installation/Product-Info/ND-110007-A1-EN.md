## Page 2

# COLOUR TERMINAL

## INTRODUCTION

The ND 110007 Colour Terminal is a low-cost colour terminal with almost full NOTIS functionality. This terminal can be used for all of Norsk Data's interactive systems, - for text as well as for data processing, and it is supplied and sold by Norsk Data A.S.

The ND 110007 is based on a VT100-compatible terminal. A special feature of the Colour Terminal is that the user can define a colour combination for each VT100 attribute, or a combination of these. Software for monochrome terminals can be converted to operate in colour, with this feature.

## FEATURES

- 64 colour combinations
- 14” screen
- Separate low profile keyboard
- Uppercase and lowercase characters, including line drawing, histogram, numeric subscript/superscript, Greek letters
- Insert, delete, copy, underline, move and erase functions
- A low-cost colour terminal for information and text
- Direct cursor addressing from host
- Cursor position report to host
- Local and remote printer control, giving hardcopy, terminal bypass or transaction logging
- PUSH-keys allowing commonly used words, or controlled words or control strings to be transmitted by pushing a single key. The strings associated with PUSH-keys can be stored in nonvolatile memory and are not lost when the power is turned off.
- All switches reside in nonvolatile memory ensuring simple set-up. Set-up is done with the aid of self-explanatory menus
- Full-screen editing

## PRODUCT DESCRIPTION

The ND 110007 Colour Terminal has 24 lines by 80 characters flicker-free display, which gives extensive character graphics capabilities. One-touch tilt and brightness control makes the terminal comfortable to use. The Colour Terminal is produced in Danish, English, US ASCII, Norwegian and Swedish versions.

## Technical Specifications

### Display

| Feature             | Description                                                                                                 |
|---------------------|-------------------------------------------------------------------------------------------------------------|
| CRT                 | 14-inch diagonal, high contrast, anti glare, high-resolution CRT (.31mm), pre-converged, manual degaussing  |
| Colours             | 8 programmable colours, 64 combinations                                                                     |
| Format              | Two pages of 24 lines by 80 columns                                                                         |
| Character Matrix    | 5x8 dot character size plus underscore contained in a 7x12 dot character cell                               |
| Character Set       | 128 standard alphanumeric characters, semigraphic Greek and mathematical character sets                      |
| Cursor Type         | Block, underscore (selectable from set-up menu or by host command)                                          |
| Cursor Attributes   | Blinking, invisible (selectable from set-up menu or by host command)                                        |
| Graphic Rendition   | 8 foreground and 8 background colours, primary rendition, bold, low-intensity, underscore, blink, reverse image, concealed characters |
| Automatic Colour    | Colour assignment of 16 combinations of VT-100 display attributes (blink, underline, low-intensity, reverse video and normal) Selectable from setup-mode or 24 combinations under host control |
| Tilt                | Variable position tilt adjustment from 0º to 15º off vertical                                               |

### Keyboard

#### General
- Detached with 6' coiled cable
- 109-keys standard + 4 local keys
- Cursor control key: left, right, up, down
- No scroll key
- Operator selectable keyclick
- LED indicator for alpha-lock
- Repeat key

#### Auxiliary keypad
- 18-key numeric cluster with period, comma, minus, enter, and 4 'NOTIS-keys'.

#### Programmable
- 24 function keys standard. Unshift and shift modes are used as NOTIS keys. Control mode can be programmed from the terminal (PUSH-keys). Up to 40 characters can be programmed per key.

#### Tilt
- Two tilt adjustment position , 4º or 11º

### Communications

| Feature          | Description                                                                                                                                               |
|------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Control Codes    | VT-100 (ANSI X3.64), VT-52 compatible plus commands specially made for the ND version                                                                      |
| Host Port        | Serial asynchronous data communications, EIA standard RS-232CCITT-V.24 and 20 mA current loop at several baudrates                                        |
| Parity           | Even, odd, none, even ignore, odd ignore                                                                                                                  |
| Handshaking      | XON/XOFF and hardware handshaking                                                                                                                         |
| Printer Port     | Serial asynchronous data communications, EIA standard RS-232CCITT-V.24, transmit only, at several baudrates (see below). Colour printer support          |
| Baudrates        | 50, 75, 110, 134.5, 150, 200, 300, 600, 1050, 1200, 1800, 2000, 2400, 4800, 9600, or 19,200                                                                |
