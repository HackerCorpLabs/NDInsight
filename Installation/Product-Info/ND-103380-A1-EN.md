# Introduction

The VDU/printer console, which is made up of ND 103380 ND 2200-3 terminal, ND 104701 Epson LX-80 printer and ND 103290 console stand is designed to be flexible to meet the different needs. The system functions as a dedicated console together with the ND-100/CX and the ND-500/CX series, and as a combined console and workstation on the ND-100 Compact and ND-100 Satellite systems.

# Features

- May be used both as console and workstation on the ND-100 Compact and ND-100 Satellite systems.
- 15" screen unit with anti-reflex faceplate.
- Low profile keyboard.
- One-page print buffer enabling printing to be done as a background task.
- Bidirectional printing.
- 9x9 dot matrix for characters.
- Audio and visual signals when out of paper.
- The VDU is ergonomical and more convenient to use than a hard-copy terminal.
- Correspondence quality printing (NLQ).

# Product Description

In the 'console mode', when used as a dedicated console, all input to the Video Display Unit (VDU) is also copied to the Epson printer.

In the 'combined mode', when used both as a console and as a workstation, all error messages are routed to the Epson printer and the VDU can be used as a normal workstation.

When used as a dedicated console, the terminal communicates at 9600 baud. When used as a combined console and workstation, it communicates at 4800 baud. The communication speed between the terminal and the printer is 9600 baud in both configurations.
