# ND-LINK/PC-LINK

## Introduction

The ND-LINK and PC-LINK programs allow users with an ND Personal Computer, or a compatible IBM PC/XT/AT* to communicate with an ND-100 or ND-500 computer system as a terminal running full-screen-oriented programs, and to transfer files between the two computers.

When the ND-PC is used as a terminal, the ND-LINK emulates the NOTIS functions with the F1 to F10 function keys on the PC keyboard in conjunction with the CTRL, ALT and/or SHIFT keys.

A help menu makes it easy to remember which keys represent the NOTIS function.

When transferring files between the two computers, the user may select the following protocols:

- Binary/text files ensuring a completely error-free transmission.
- XON/XOFF for low-volume, non-critical information.

During binary/text file transfers the programs check that data blocks are correctly received, and automatically perform retransmissions if time-out or missing characters occur.

The program displays the progress of the file transfers. A number of features make the program easy to use:

- Extensive help pictures
- Line parameters may be set with default values or values stored on files
- Pushkeys for recurrent keystrokes such as log-on names or long command sequences
- Saving screen pictures on file
- Sending commands or data stored on files to save expensive line costs, and recording of all data received on files for later inspection.

The ND-LINK program can communicate simultaneously with two computers, each having different transmission characteristics, and the user may switch between two screen forms with a single keystroke.

For colour monitors, the user may change colour settings to suit his own taste. The setting is saved for future reference.

# ND-LINK/PC-LINK

## Features

- Terminal mode using ND-PC (or another PC) to communicate with ND-100/500 systems or other computers using asynchronous lines, from 300 to 19200 bauds
- NOTIS-terminal emulation, using function keys F1 to F10 with the CTRL, ALT and SHIFT keys to match NOTIS function keys
- Extensive help pictures and menu selection make the programs easy to learn and easy to use
- Line parameters may be stored on files for fast setup
- Pushkeys, stored on files, save typing of recurrent log-on procedures or command sequences
- Supports colour monitors, allowing the user to change colours on background, foreground, underlining and inverse characters, to suit personal taste
- Two communication ports may be in operation at the same time; a single command selects active port and/or screen
- Printing and/or capturing data onto files, and taking screen dump to files when needed

## Requirements

- A Norsk Data computer system running the SINTRAN III operating system, version H or later
- A Norsk Data-approved personal computer, with at least 192KB of RAM, and one or two asynchronous communication ports
- The personal computer must run the PC-DOS(1) or MS-DOS operating system, version 2.10, or later

For communication with an ND computer using direct lines, the following cables should be used:

| Cable | Description |
|-------|-------------|
| ND-964 | ND-PC connection to ND host using RS232C |
| ND-965 | IBM-PC connection to ND host using RS232C |
| ND-966 | Adapter, ND-PC (RS232C) to ND host (20 mA current loop), Telex plug at ND end |
| ND-967 | Adapter, IBM-PC (RS232C) to ND host (20 mA current loop), Telex plug at ND end |
| ND-968 | Adapter, ND-PC (RS232C) to ND host (20 mA current loop), for connection directly to ND host |
| ND-969 | Adapter, IBM-PC (RS232C) to ND host (20 mA current loop), for connection directly to ND host |

For connection with the ND computer over telephone lines:

- Full duplex asynchronous modem of the dial-up type, unless used over leased line. This may be supplied by the local telephone service or, in some countries, by other vendors
- Cable to connect the PC to a modem, normally supplied by the PC vendor
- ND-970 cable for ND-PC (RS232C) to an asynchronous dial-up modem or
- ND-971 cable for IBM-PC (RS232C) to an asynchronous dial-up modem

## Product Description

The ND-LINK program runs in the ND-PC under MS-DOS(1) 2.1 or later, and lets the user select from a menu whether to transfer files to or from the PC, or to connect the PC as a terminal to the ND computers.

In **TERMINAL-MODE**, the user has available a number of direct commands, which can be used to send or receive character-oriented files, store screen dump on a file, change line parameters, or use pushkeys for recurrent commands. Quick help-picture and display of status information are available using direct commands. All such direct commands use the combination of SHIFT + ALT so that they can be issued between any "normal" characters.

In **TRANSFER-FILE**, the user can choose between byte or binary-orientated mode. In byte-orientated transfers a character conversion table may be applied, to ensure compatibility with standard IBM applications and keyboard utilities.

Conversion tables for USA, England, France, Germany, Sweden and Norway are included. Conversions are applicable in TERMINAL-MODE as well.

The PC-LINK program running in the ND-100/500 computer is only used when transferring files using the "SAFT" protocol. The user will normally start this program in TERMINAL-MODE, perhaps by one of the pushkeys. The PC-LINK and ND-LINK programs cooperate by enclosing data blocks in communication "envelopes" that ensure error-free transmissions. Should a data block in some way be corrupted, the receiving program will request that the data block be repeated by the sender program.
