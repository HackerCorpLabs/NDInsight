# SYNCHRONOUS MODEM CONTROLLER

## INTRODUCTION

The ND 107010 — Synchronous Communication Adapter — is designed to meet the CCITT V.24 or EIA RS-232 C standards. The communication adapter may operate in synchronous character mode or in binary synchronous transparent mode. The adapter requires one standard I/O slot.

## FEATURES

- CCITT V.24 or EIA RS-232 C compatible
- Transmission rate up to 307.2 kbits/sek.
- Programmable character length from 5 to 8 bits
- Even or odd parity or no parity
- Half or full duplex operation
- Automatic detection of overrun (character lost)
- The flexible design enables one to communicate with IBM, Univac, Control Data, Honeywell Bull by using the relevant synchronous communication protocol.
- Programmable SYN characters

## PRODUCT DESCRIPTION

The design of the adapter has been based on a Universal Synchronous Receiver/Transmitter using MOS/LSI technology. This approach gives great flexibility in that data word length, parity mode, and receiver synchronization character are independently programmable. The adapter is double buffered (one character), which eliminates the need for precise external timing. The baud rate is determined by the Data Set.

All data transmission is continuously checked for:

- Proper synchronization through automatic detection of SYN characters
- Parity Error
- Character overrun — lost data is overwritten during input
- Missing carrier
- Connect missing
- Data Set Ready missing

## SPECIFICATIONS

Conforms to CCITT V.24 or EIA RS-232 C standards.

Transmission rates 1200, 2400, 4800 or 9600 Bps (rate is Data Set dependent). 19.2 - 38.4 - 76.8 - 153.6 - 307.2 kbits.

| Character length | Parity |
|------------------|--------|
| 5, 6, 7 or 8 bits| Even or odd or none |

Receiver and Transmitter SYN characters are independently programmable.
