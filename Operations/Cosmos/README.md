# COSMOS Network Operations Documentation

**Operator and programmer guides for the COSMOS network software on ND-100 systems**

---

## Overview

This folder contains official Norsk Data documentation for the COSMOS network software — operator guides, programmer references, and protocol-specific manuals covering X.21, X.25, and TCP/IP integration.
